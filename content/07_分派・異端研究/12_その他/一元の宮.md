# 一元の宮 専門構造分析ノート

> [!summary] 要旨
> 一元の宮（旧称：大日大立元理教団）は、1950年（昭和25年）に元木勝一（本名：勇）によって立教された新宗教団体。本部は大阪府大阪市天王寺区（四天王寺付近）、主要拠点は大阪府八尾市と奈良県平群町の府県境に位置する高安山山中の広大な修行・共同生活施設「秀峰園（約7万坪）」。樹木を神体として崇敬し自主自給生活を営む。1972年/1974年の「6月18日大地震予言」外れと創始者の割腹自殺未遂事件で波紋を呼んだ。全盛期には高安山拠内に信者有志による内部サークル「[[宇宙念波研究会]]」が設立されていた。

## 2. 創始者と沿革

### 闘病・霊託体験と立教
創始者の元木勝一（本名：元木勇）は1906年（明治39年）3月、北海道空知郡の製材業を営む家庭に生まれる。高等科卒業後に大阪へ出、工場労働に従事する中で1928年頃に重度の肺結核に倒れ余命数ヶ月と宣告されるが、神の声を聞いて奇跡的に全快。深谷霊谷での修養を経て「霊身一体宇宙一元の大元理を解き世界を救え」との霊示を受け、1950年10月に「大日大立元理教団」を設立した。1952年に宗教法人登記を行い、1964年に「一元の宮」へ改称。最盛期には約1万人の信者を擁した。

### 6月18日「大地震予言」と割腹自殺未遂・釈明声明
1970年代前半（1972年または1974年）、教団は「6月18日午前8時に大地震が発生する」とする神託を受け、大阪や名古屋のビル屋上から大量の警告ビラを撒布。信者らは家財・土地を売却して高安山等の山間部へ避難した。

当日の指定時刻（6月18日8時）、マスコミが教団施設に大挙殺到する中で地震は発生せず、予言は外れた。元木は自室に閉じこもり白衣姿で割腹自殺を図ったが、早期発見により命を取り留めた。

怪我の治療後、元木は**「私が自ら腹を割いたことで、大地震を止めることができた」**という声明を発表。しかし、この釈明を真に受ける信者は少なく、1万人を超えた信者は100人程度にまで急減した。元木は1981年に没し、中島教絵が教主を継承した。

## 3. 高安山「秀峰園」と生活・信仰構造

### 1. 7万坪の聖域「秀峰園」と自給生活
大阪府八尾市と奈良県平群町の境界にまたがる高安山山頂付近の約7万坪の土地は、地元の信者たちによって教団に寄贈された聖域。「秀峰園」と呼ばれ、信者が自分で湯呑み等を制作する陶芸室や、自主的な修行・自給生活のための設備が整えられている。

### 2. 樹木崇拝と植木の手入れ
教団では**「木（樹木）を神様（御神木）」**として崇める教理が存在する。そのため信者自身が剪定のために樹木を切ることは信仰上禁じられており、専轄の植木担当者によって樹齢100年を超えるサツキ等の手入れ・管理が行われている。

### 3. [[宇宙念波研究会]]との関係
高安山「秀峰園」の敷地内には「宇宙念波研究会」の看板が掲げられている。これは1950〜60年代の教団全盛期に、信者有志が「宇宙と交信・修養する」目的で設立した内部グループの名残であり、現在は実質的に活動休止・看板のみが存続する状態となっている。

## 4. 歴史変遷クロノロジー

```
・1906年 (明治39年): 元木勝一、北海道空知郡に生まれる。
・1928年 (昭和3年):  肺結核全快体験と霊告拝受。
・1950年 (昭和25年): 「大日大立元理教団」を立教。高安山拠点の形成。
・1952年 (昭和27年): 宗教法人格を取得。最盛期に向け信者数1万人に達する。
・1960年代:         高安山「秀峰園」内に信者有志による「宇宙念波研究会」設置。
・1964年 (昭和39年): 教団名を「一元の宮」に改称。
・1972/1974年:      6月18日大地震予言不成立。創始者の割腹未遂と「腹を割いて地震を止めた」声明。信者急減。
・1981年 (昭和56年): 創始者他界。中島教絵が教主継承。
```
