# 明治の教難と教祖牢くぐり

> [!summary] 要旨
> 明治政府・警察当局による天理教取締りの中で、教祖・[[中山みき]]は複数回にわたり取調べ・拘留を受けた。最後の拘留は1886年（明治19年）2月18日から3月1日まで、櫟本警察分署にて12日間、89歳（数え年）で受けたもので、「最後の御苦労」と呼ばれる。

---

## 1. 最後の拘留（確認できた事実）

| 項目 | 内容 |
| :--- | :--- |
| **時期** | 1886年（明治19年）2月18日（陰暦正月15日）逮捕 - 3月1日（陰暦正月26日）釈放 |
| **場所** | 櫟本警察分署 |
| **期間** | 12日間 |
| **年齢** | 89歳（数え年） |
| **付添** | 「おひさ」が付き添い、12日間一睡もしなかったと証言 |

---

## 2. その他の拘留歴（要検証）

- 明治17年8月18日にも奈良警察署丹波市分署にて拘留を受けたとする記録がある（12日間）。
- 「合計12回の取調べ・拘留」という総回数の主張は、複数の資料で言及されるが、正確な回数・各回の年月日・場所を網羅した一次資料での裏付けは未確認。個別の回次の詳細は今後の検証課題とする。

---

## 3. 宗教学的・歴史社会学的意義

- 教祖中山みきは警察の連行・取調べに対し、天理教の教えでは「陽気ぐらしの実践」として受け止められたとされる（教団史・信仰的解釈であり、外部の学術的評価とは区別する）。
- [[櫟本分署跡保存会]]（八島英雄が設立）は、この最後の拘留の現場を保存する活動を行っている。
