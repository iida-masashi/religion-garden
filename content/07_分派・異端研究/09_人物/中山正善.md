# 中山正善 人物専門構造分析ノート

> [!summary] 要旨
> 中山正善（1905-1967）は、天理教二代真柱。教祖・中山みきの曾孫にあたり、父である初代真柱・中山眞之亮（中山みきの孫）の逝去後、1915年に10歳9ヶ月で管長（真柱）に就任した（幼少期は山澤為造が職務代行）。教典整備（『おふでさき』『おさしづ』『天理教教典』刊行）、天理外国語学校（後の天理大学）設立、天理図書館・天理参考館設立など、近代天理教の教学・組織基盤を確立した人物である。

## 2. 経歴と天啓・覚醒の経緯

該当なし（正善自身は天啓を主張する立場ではなく、教団の最高指導者・組織運営者としての立場）。

- 父・初代真柱中山眞之亮が1914年12月31日に逝去。
- 翌1915年1月21日、10歳9ヶ月で管長（真柱）に就任。幼少期は山澤為造が職務代行。

---

## 3. 詳細歴史クロノロジー

```
・1905年4月23日: 誕生。
・1914年12月31日: 父・中山眞之亮（初代真柱）逝去。
・1915年1月21日: 二代真柱（管長）就任（10歳9ヶ月、山澤為造が職務代行）。
・1925年: 天理外国語学校（後の天理大学）設立、校長就任。
・1948年: 『おふでさき』『おさしづ』刊行。
・1949年: 『天理教教典』刊行、天理教学の体系を確立。
・1967年11月14日: 死去。
```

---

## 4. 思想・教理的貢献

- 『天理教教典』の刊行により、今日の天理教学の教義体系を確立したとされる。
- 天理図書館（稀少本図書館）・天理参考館（博物館）の設立により、天理教研究の学術的基盤を整備した。
