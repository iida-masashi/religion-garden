# 東京・関東周辺の天理教系分派

天理教系教団・分派・関東拠点に関する専門分析ノート。

---

## 1. 概要と基本情報

| 項目 | 内容 |
| :--- | :--- |
| **地域対象** | 東京都および関東周辺（神奈川、埼玉、千葉） |
| **主要対象教団** | 太道教、ほんみち（関東宝場）、ほんぶしん（関東精舎）、世界心道教 |

## 2. 沿革と地域別・教団別詳細

### ① 太道教（たいどうきょう）
- **本部所在地**: 東京都杉並区阿佐谷南1丁目1-38
- **創始・歴史**: 創始者は中村しげ。1938年（昭和13年）霧島神宮の関東における講元となり、1940年（昭和15年）瓊瓊杵尊の天孫降臨の事績を顕彰する宗教結社「太道教」を設立。戦後、本部に隣接して猿田彦神社を創建。天理教系という位置づけ・関根豊松との関連は誤りで、詳細は[[太道教]]参照。
- **神観・教理**: 太道教本部は「瓊瓊杵尊」を主祭神とし、隣接する猿田彦神社は「猿田彦大神」（道開きの神）を祀る。

### ② ほんみち（関東宝場拠点）
- **創始者**: [[大西愛治郎]] / **本部**: 大阪府高石市
- **関東の拠点**: 東京都内（足立区・板橋区など）、埼玉県、千葉県、神奈川県に関東地区の**「宝場（たからば / 信者集会所）」**を展開し、人間甘露台の理に基づく神事・集会を実施。

### ③ ほんぶしん（関東精舎拠点）
- **創始者**: 大西玉（ほんみち創始者・大西愛治郎の娘） / **本部**: 岡山県岡山市
- **関東の拠点**: 東京・神奈川・千葉等の関東エリアに精舎・集会所を開設。

### ④ 世界心道教（せかいしんどうきょう）
- **創始者**: 会田ヒデ（天理教元教師・ほんみちを経て創始） / **本部**: 愛知県豊川市
- **関東の拠点**: 東京都および神奈川県などに関東地区の教会・布教所を展開。

## 4. 宗教学的・社会学的考察

### ① 大都市圏（首都圏）における天理教系分派の受容構造
- 地方から上京した労働者・信者層に対し、奈良の本部へ頻繁に帰参できない距離的制約の中で、関東の「宝場」「精舎」「単立神社」が身近な救済と霊的コミュニティの機能を果たした。
