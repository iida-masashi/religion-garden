# 朝日神社 専門構造分析ノート

> [!warning] 執筆前の確認事項
> - Vault内には過去「朝日教」という別ノートが存在した。奈良県・関西一円で明治初期〜10年代に発生したとされる「朝日拝み」運動を扱っていたが、実在の裏付けが得られず、国立国会図書館デジタルコレクション・CiNiiの悉皆検索でも痕跡が見つからなかったため2026-07-27に削除済み。本ノートが扱う「朝日神社」は兵庫県三木市に実在が確認できる宗教法人であり、時代・場所・教義のいずれも「朝日教」とは一致しない別団体だった。
> - 法人番号検索時、同名の全くの別法人「朝日神社」（千葉県茂原市、法人番号8040005010982）がヒットするため注意。本ノートの法人番号8140005006013はgBizINFOで所在地が「兵庫県三木市別所町高木817番地」であることを確認済み。

> [!summary] 要旨
> 朝日神社は、天理教信徒だった井出国子（井出クニ、1863-1947）が明治41年（1908年）頃の神がかり体験を経て、天理教本部から実質的に離れた後、兵庫県三木市別所町高木の地に築いた独自拠点を起源とする単立宗教法人。昭和21年（1946年）に宗教法人令に基づき法人登記された。天理教教義（おふでさき等）を継承しているとされる情報もあるが、天理教本部からの公式な分派・系譜承認は得られておらず、井出国子個人の霊的権威に基づく独立系の新宗教として位置づけるのが妥当と考えられる。

## 3. 創始者と沿革

詳細な創始者の経歴は[[井出国子]]を参照。要点のみ記す。

井出国子は兵庫県三木市出身の天理教信徒で、明治41年（1908年）頃に神がかりを体験したと主張し、「播州の親様」「天理教二代目教祖」等と呼ばれた。しかし天理教本部はこの帰神を公式には認めておらず、大正5年（1916年）の本部参拝時には本部員との間で摩擦（負傷）が生じたとされる。この一件を境に天理教本部から実質的に距離を置くようになったとみられる。

その後、兵庫県三木市別所町高木の地に独自の拠点・社殿を築き、昭和21年（1946年）に「朝日神社」として宗教法人登記した。晩年、井出は「天理世界教」という名称を用いたとする記録もあるが、これが正式な教団名として定着したかは未確認。

## 4. 歴史変遷クロノロジー

```
・1908年（明治41年）: 井出国子、神がかりを体験（45歳）
・1909年（明治42年）: 一日100人規模の来訪者。施設建設
・1910年（明治43年）: 予審裁判で「人助けは罪にならない」との判断（Wikipedia記事）。お助け場所落成
・1911-1912年（明治44-45年）: 天理教管長へ書状送付するも返答なし（ide-kuniko.com年譜）
・1916年（大正5年）: 中山みき三十年祭で天理教本部訪問時、本部員に負傷させられる
・1935-1936年（昭和10-11年）: 三木市別所町高木の地に社殿造営（出典間で年次1年の食い違いあり）
・1946年（昭和21年）4月6日: 宗教法人令に基づき「朝日神社」として法人登記
・1947年（昭和22年）: 井出国子、84歳で死去
```

## 5. 教理・儀礼の特色

井出国子個人の霊能（霊視・千里眼・病気治し・予言）を中心とした信仰とされる。子孫運営の顕彰サイトでは、「病は心の持ち方」とする趣旨の教えや、天理教の「おふでさき」「陽気ぐらし」の教えとの関連が示唆されているが、これらは第三者による学術的検証を経たものではなく、本ノートでは未確認情報として扱う。
