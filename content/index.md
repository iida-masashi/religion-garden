Obsidian Vault から Quartz v4 を介して公開する、**日本の新宗教・分派・異端教団に関する学術的構造分析ノート群**です。
天理教系・大本系・世界救世教系・教派神道十三派・法華日蓮系・キリスト教系異端・手かざし系・自己啓発カルトなど、各教団の創始者・教理体系・組織構造・歴史的変遷・法廷確定判決・分派系統を客観的かつ体系的に分析・記録しています。

## 🌟 【注目・重点分析】社会的関心の高い重要教団ノート

現代の宗教社会学、法廷闘争、信教の自由と公序良俗の境界、カルト問題の焦点となった重要教団について、**最新の10セクション標準フォーマット**に基づく全面大拡充を実施しています。

### 1. 旧オウム真理教および後継分派群（公安監視・法廷闘争史）
- **[[オウム真理教]]** — 宗教法人解散、地下鉄サリン事件、テロリズムの構造分析
- **[[Aleph]]** — 主流派後継組織。麻原次男派指導部、資産隠蔽と全国初の活動制限命令
- **[[ひかりの輪]]** — 上祐史浩による脱麻原・東西の智恵路線。観察処分取消訴訟（最高裁確定）
- **[[山田らの集団]]** — 金沢・野々市を拠点とする麻原絶対原理主義派。密室礼拝と公安監視

### 2. キリスト教系・世界的展開教団と社会問題
- **[[世界平和統一家庭連合]]**（旧統一教会） — 文鮮明と原理講論、霊感商法・高額献金裁判、解散命令請求
- **[[エホバの証人]]** — 統治体神権制、三位一体否定、輸血拒否最高裁判決（人格権侵害）、鞭体罰と厚労省指針

### 3. 法華・日蓮系富士門流の激烈な正統抗争
- **[[創価学会]]** — 戸田城聖・池田大作、日蓮正宗からの独立、「昭和52年路線」と世界展開
- **[[日蓮正宗]]** — 富士門流総本山大石寺、戒壇の大御本尊、血脈相承、学会破門の経緯
- **[[正信会]]** — 学会宥和と日顕登座に反発した青年僧侶200名の擯斥、全国寺院明渡し訴訟
- **富士大石寺顕正会** — 浅井昭衛、国立戒壇論、強烈な折伏活動と終末論
- **[[国柱会]]** — 田中智学、近代日蓮主義、宮沢賢治や石原莞爾への思想的影響

### 4. 教派神道・新宗教・生活芸術
- **[[パーフェクトリバティー教団]]**（PL教団） — 「人生は芸術である」、PL学園野球部の栄光と休部、大平和祈念塔
- **[[天理教]]** — 中山みき、「陽気ぐらし」、つとめ・おてふり、教派神道からの独立
- **[[大本]]** — 出口なお・出口王仁三郎、大本事件（国家弾圧）、生長の家や天行居への思想的源流
- **[[解脱会]]** — 岡野聖憲、真言密教・天台宗・神道習合、伊勢神宮親任式、新宗連創設

### 5. 自己啓発・霊能治病・組織的詐欺カルト
- **[[ライフスペース]]** — 高橋弘二、頭部打擲（シャクティパット）、成田ミイラ化遺体事件、不真正不作為犯最高裁判決

## 🔬 本研究の分析フレームワーク（10セクション標準フォーマット）

本デジタルガーデンに収録されている教団ノートは、客観的・中立的な宗教学・法学分析を担保するため、以下の**10セクション標準構造**に準拠して記述されています。

| セクション | 分析項目 | 記録内容と基準 |
| :---: | :--- | :--- |
| **第1節** | **概要と基本情報** | 正式名称、法人格（包括・単立・任意団体）、本尊・教祖、信徒数（公称および公的推計） |
| **第2節** | **教団系統樹（Mermaid 11）** | 母体教団からの分派独立、内部対立、後継組織の歴史的系譜をダイアグラムで可視化 |
| **第3節** | **指導層と後継構造** | 創始者の思想的背景、歴代代表者、後継指名方式、親族世襲問題 |
| **第4節** | **歴史変遷クロノロジー** | 立教から拡大期、国家弾圧、内紛、現代に至る確定年表 |
| **第5節** | **教理・信仰・実践の特色** | 核心教義、救済論、修行・儀礼、信徒の生活規律（食事・献金・医療制限等） |
| **第5-1節** | **事件・裁判・社会的議論** | 刑事・民事確定判決、公安調査庁等の公的報告、解散命令請求、客観的事実の記録 |
| **第6節** | **拠点施設・アクセス** | 本部・聖地・主要道場の所在地、交通アクセス、巡礼地情報 |
| **第7節** | **組織形態・関連企業・機関紙** | 法人構造、関連企業網、学校法人・公益法人、定期刊行物・広報媒体 |
| **第8節** | **史料・参考文献** | 一次史料（教団公刊物・原典）、確定判決録、官公庁統計、宗教学術論文 |
| **第9節** | **関連ノート（内部リンク）** | Vault内の母体教団、分派教団、比較教団、創始者人物ノートへの双方向リンク |
| **第10節** | **検証・品質ゲートと留保事項** | `confidence`（確度1〜5）、`evidence_type`、未検証事項の透明な開示 |

## 📖 読み方と学術的姿勢（品質ゲート）

> [!important] ファクトベース・一次情報主義と留保事項
> - **客観性と中立性**: 本研究ノートは特定の宗教団体を擁護または糾弾することを目的とせず、宗教社会学・教理史・法解釈の観点から客観的・中立的に構造化されています。
> - **確定記録の重視**: 事件や不祥事に関する記述は、最高裁判所等の確定判決録、官公庁統計、警察白書、および公安調査庁公表資料などの公的記録に基づいて執筆されています。
> - **メタデータによる確度開示**: 各ノートのフロントマターには、研究の信頼度を示す `confidence`（1: 仮説段階 〜 5: 一次史料・確定判決で検証済み）と `evidence_type`（典拠種別）を明記しています。
