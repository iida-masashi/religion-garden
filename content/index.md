# 日本の新宗教研究

![日本の新宗教のロゴ（AI生成イメージ・各教団の実際のロゴ意匠とは異なるイメージ画像）](/static/new-religions-logos-ai.png)

Obsidian Vault から Quartz を介して公開する、日本の新宗教・分派・異端教団に関する研究ノート群。天理教系・大本系・世界救世教系・教派神道十三派・法華日蓮系・キリスト教系異端・手かざし系など、各教団の創始者・教義・法人格・系譜・史的経緯を個別に分析する。

---

## 構成

- 🏛 **[[_分派・異端研究ポータル]]** — 全領域を俯瞰する中央ハブ（史論・個別教団・人物・裁判史・家系図・拠点一覧）
- 📚 **[[系統別分類カタログ]]** — 系統・出自別（天理教系、大本系等）の横断索引

---

## 研究成果のまとめ

242件のノートを17系統に分類。各教団の創始者・教義・法人格・分派関係を個別に分析するほか、系統横断の比較・史論ノートも整備している。

### 系統別の内訳

| 系統 | 件数 | 特色 |
| :--- | ---: | :--- |
| 天理教系 | 19 | 分派研究の中心領域。「甘露台」の解釈や場所を巡る分派間の対立、裁判史（[[天理教豊文教会]]の名称差止訴訟等）、家系図まで多層的に分析 |
| 世界救世教・真光系 | 21 | 岡田茂吉創始の世界救世教から分かれた「真光」系教団群の系譜が特に濃密（[[崇教真光]]・[[神慈秀明会]]等） |
| 教派神道十三派 | 12 | 明治期に公認された教派神道の主要教団（[[黒住教]]・[[金光教]]・[[出雲大社教]]等）を体系的に収録 |
| 大本系 | 6 | [[大本]]から派生した[[生長の家]]・[[神道天行居]]等の思想的系譜を追跡 |
| 法華・日蓮系 | 8 | [[創価学会]]・[[立正佼成会]]・[[霊友会]]など国内最大級の新宗教教団を含む |
| キリスト教系・異端 | 5 | [[世界平和統一家庭連合]]（旧統一教会）等、社会問題化した教団も収録 |
| 手かざし・霊能・心霊系 | 6 | [[ワールドメイト]]・[[白光真宏会]]等の霊能・心霊系教団 |
| 神道系 | 24 | 神道系の新宗教・単立教団を幅広く収録 |
| 仏教系 | 14 | 仏教系の新宗教・単立教団 |
| 比較・史論・ハブ | 21 | 教義比較マトリクス（[[天理教系諸派の教義比較マトリクス]]等）や横断的な史論を集約 |
| 人物 | 28 | 中山みき・出口王仁三郎・岡田茂吉など創始者・指導者の専門ノート |
| 概念・原典・事件・拠点 | 28 | 各教団の教義概念・原典・弾圧事件史・聖地拠点の分析 |

| ユダヤ教系・ヒンドゥー系・飲食関連 | 16 | 比較宗教学的な観点からの周辺領域ノート |

### 特に厚みのある研究領域

- **天理教の分裂史** — [[天理教の分裂の系譜]]・[[天理教分派・異端教団一覧]]を中心に、[[ほんみち]]・[[ほんぶしん]]など主要分派の教義的差異と、明治期の弾圧史（[[明治の教難と教祖牢くぐり]]等）、裁判史を統合的に追跡。
- **世界救世教から分かれた真光系教団群** — [[崇教真光]]・[[神慈秀明会]]など、岡田茂吉の思想を受け継いだ教団の分派関係を系譜図で整理。
- **創始者の伝記研究** — [[中山みき]]・[[出口なお]]・[[出口王仁三郎]]・[[岡田茂吉]]など、各教団創始者の生涯と啓示体験を一次資料に基づいて分析。
- **教義比較マトリクス** — 同系統内の複数教団を横断的に比較する分析ノート群（天理教系・大本系・手かざし系）。
