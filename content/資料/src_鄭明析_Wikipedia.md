**鄭 明析**（チョン・ミョンソク、Jung Myung Seok、[1945年](https://ja.wikipedia.org/wiki/1945年 "1945年")[3月16日](https://ja.wikipedia.org/wiki/3月16日 "3月16日") - ）は、[韓国](https://ja.wikipedia.org/wiki/大韓民国 "大韓民国")の宗教団体「[キリスト教福音宣教会](https://ja.wikipedia.org/wiki/キリスト教福音宣教会 "キリスト教福音宣教会")」（摂理）の創立者。1999年に起きた元信者女性の拉致・監禁事件について、鄭による女性信者への性的暴行が告発されている。[*[要出典](https://ja.wikipedia.org/wiki/Wikipedia:「要出典」をクリックされた方へ "Wikipedia:「要出典」をクリックされた方へ")*]

2009年に女性信者への強姦及び準強姦罪で懲役10年の実刑判決を受けた。

## 経歴

### 生い立ち

[日本統治時代の朝鮮](https://ja.wikipedia.org/wiki/日本統治時代の朝鮮 "日本統治時代の朝鮮")の[全羅北道](https://ja.wikipedia.org/wiki/全羅北道_(日本統治時代) "全羅北道 (日本統治時代)")[錦山郡](https://ja.wikipedia.org/wiki/錦山郡 "錦山郡")珍山面で、七人兄弟の三男として生まれる。[第二次世界大戦](https://ja.wikipedia.org/wiki/第二次世界大戦 "第二次世界大戦")から[朝鮮戦争](https://ja.wikipedia.org/wiki/朝鮮戦争 "朝鮮戦争")という動乱期に生まれ、飢えと貧困に苦しむ中で人生の意味と神とを模索し始める。

青年期[ベトナム戦争](https://ja.wikipedia.org/wiki/ベトナム戦争 "ベトナム戦争")に2度派兵され、命が尊いものであることを「骨身にしみるほど」悟り、帰還後無事であったことを感謝して、故郷のキリスト教会建て直し資金に軍務で得た給金を差し出した。

昼は両親の農作業を手伝い、夜は山や洞窟で明け方まで[聖書](https://ja.wikipedia.org/wiki/聖書 "聖書")を読み祈るという生活を続けた。

### 宣教活動

1978年6月にソウルで宣教を始め、[1981年](https://ja.wikipedia.org/wiki/1981年 "1981年")3月に現在の「キリスト教福音宣教会」の前身である「MS宣教会」を立ち上げる。1999年に現在の「キリスト教福音宣教会」(CGM)を発足する。1999年から海外宣教を始める。(日本、ドイツ、フランス、イギリス、台湾など)　1989年7月から会員と共に自身の故郷を[月明洞](https://ja.wikipedia.org/wiki/月明洞?action=edit&redlink=1 "月明洞 (存在しないページ)")（ウォルミョンドン）として開発し、岩や木、水など自然によって作り上げた聖殿「自然聖殿」を建築する。

### 裁判と判決

[2001年](https://ja.wikipedia.org/wiki/2001年 "2001年")6月、韓国での女性信者に対する[強姦](https://ja.wikipedia.org/wiki/強姦 "強姦")容疑などで[国際手配](https://ja.wikipedia.org/wiki/国際手配 "国際手配")され、[2007年](https://ja.wikipedia.org/wiki/2007年 "2007年")[5月11日](https://ja.wikipedia.org/wiki/5月11日 "5月11日")に中国で捜査当局により婦女暴行の容疑で逮捕され、犯罪人引渡し条約により韓国に送還される。[2008年](https://ja.wikipedia.org/wiki/2008年 "2008年")[1月11日](https://ja.wikipedia.org/wiki/1月11日 "1月11日")、[韓国](https://ja.wikipedia.org/wiki/大韓民国 "大韓民国")大法院（最高裁判所）において慰謝料約700万円の支払いが確定した。 [2009年](https://ja.wikipedia.org/wiki/2009年 "2009年")[4月23日](https://ja.wikipedia.org/wiki/4月23日 "4月23日")、韓国大法院が鄭明錫の上告を棄却し、懲役10年の判決が確定。

## 作品

鄭明錫は、創作活動に熱心で、多くの詩と絵画などの作品を残している。詩は月刊＜文芸思潮＞を通して登載されるなどしており、2011年には韓国詩文学100年史を網羅した＜韓国詩大辞典＞に詩10編が記載されている。詩集は数冊発行されている。絵画は構想美術館に数多く展示されている。

また鄭明錫の著した絵画『運命』が、2011年、アルゼンチン・アートフェアにおいて代表作品として選考された。

2013年に発刊した詩集「詩の女」と「詩で語る」は教保文庫の詩部門において1位と2位になっている。また数万におよぶ箴言を残しており、出版されているものもあるほか、詩集や陶芸品等、ジャンルは多岐に及ぶ。

## 年譜

* [1945年](https://ja.wikipedia.org/wiki/1945年 "1945年")
  + 3月16日 [第二次世界大戦](https://ja.wikipedia.org/wiki/第二次世界大戦 "第二次世界大戦")末期で、まだ日本の統治下にあった[朝鮮](https://ja.wikipedia.org/wiki/朝鮮 "朝鮮")の[忠清南道](https://ja.wikipedia.org/wiki/忠清南道 "忠清南道")（チュンチョンナムド）の [錦山郡](https://ja.wikipedia.org/wiki/錦山郡 "錦山郡")（クムサングン） 珍山面（チンサンミョン） 月明洞（ウォルミョンドン）で、6男1女の三男として生まれる。
* [1966年](https://ja.wikipedia.org/wiki/1966年 "1966年")
  + 軍隊に入り、[ベトナム戦争](https://ja.wikipedia.org/wiki/ベトナム戦争 "ベトナム戦争")に2度従軍する。
* [1969年](https://ja.wikipedia.org/wiki/1969年 "1969年")
  + 9月 軍役を終え、故郷で過す。
* [1978年](https://ja.wikipedia.org/wiki/1978年 "1978年")
  + 6月 ソウルに上京し、宣教を始める。
* [1980年](https://ja.wikipedia.org/wiki/1980年 "1980年")　韓国の五一六広場　復活祭に出席。
* [1981年](https://ja.wikipedia.org/wiki/1981年 "1981年")
  + 3月 「MS宣教教」設立。
* [1983年](https://ja.wikipedia.org/wiki/1983年 "1983年")

* [1985年](https://ja.wikipedia.org/wiki/1985年 "1985年")
  + 「ウェスレー神学院」を開設。
* [1989年](https://ja.wikipedia.org/wiki/1989年 "1989年")
  + 月明洞自然聖殿の開発を始める。
* [1995年](https://ja.wikipedia.org/wiki/1995年 "1995年")
  + 月刊＜文芸思潮＞に詩が登載される。
  + 詩人として初の著書「霊感の詩」4冊を発表
* [1999年](https://ja.wikipedia.org/wiki/1999年 "1999年")
  + 「キリスト教福音宣教会」発足
* 2001年
  + CGM奉仕団を設立
  + 国際代替医療大学医療研究センター（The Open International University for Complementary Medicines：OIUCMED）から博士号を授与
* [2002年](https://ja.wikipedia.org/wiki/2002年 "2002年")
  + 8月、教団は[ソウル放送](https://ja.wikipedia.org/wiki/ソウル放送 "ソウル放送")に対して、放送禁止を求める仮処分を申請し、損害賠償訴訟を起こした。結果、1）メディアは告発人などから提供される片方だけの情報を使用してはならない。2）メディアは放送の48時間前にはその組織に通知しなければならない。3）メディアは放送時間の5％は、反論を述べるために教会側に確保しなければならない。4）仮にこれらの命令が侵害されたなら、メディアはそれぞれの侵害行為に対して3000万ウォンを支払わなければならない。との判決が出された。[*[要出典](https://ja.wikipedia.org/wiki/Wikipedia:「要出典」をクリックされた方へ "Wikipedia:「要出典」をクリックされた方へ")*]
  + 日韓共同開催　FIFAワールドカップ　決勝戦に出席
* [2007年](https://ja.wikipedia.org/wiki/2007年 "2007年")
  + 5月 中国・北京市内で[公安当局](https://ja.wikipedia.org/wiki/中華人民共和国公安部 "中華人民共和国公安部")に身柄を拘束される。韓国の捜査当局は中国政府に身柄の引き渡しを要求。
* [2008年](https://ja.wikipedia.org/wiki/2008年 "2008年")
  + 1月 中国国務院が鄭明錫の身柄の引き渡しを正式決定。
