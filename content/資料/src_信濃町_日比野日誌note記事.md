# すしとあの人・１６５ 「池田大作」

![日比野日誌（エスパルスドリームプラザ）](images/profile_b9a19980fbfc48926b6ad6bfd5f43114.png)

昭和の宗教家です。

昭和35年（1960）、創価学会第３代会長に就任。仏教を基礎とした文明論、学問論、政治論を展開し、信者820万世帯を超えるほどに強烈な布教活動を導きました。また海外布教にも熱心で、創価学会インターナシの立ち上げ、1970年以降は宗教色を薄くした政党に改めるなどして全国に名を轟かせました。

その頃、創価学会は「社長会」と称して、創価学会の中の社長連中を集め、会への貢献を示させるものを主宰していました。その中で一番成功したのは、東西哲学書院でした。同社は創価学会本部の入り口近く、御苑東通りの慶応大学病院の向かいに位置し、博文堂書店のほか、レストラン博文を出店。創価学会員相手に収益をあげ、すし屋チェーン「満月」にも手を出して、成功を収めています。

この「満月」とレストラン博文の２階、そして聖教新聞社近くの「光亭」。池田との会食がよく使っていたのはこの３箇所が一番多かったようです。中でも青山一丁目近くにある「満月」は池田のたいそうお気に入りの店で、創価学会や公明党首脳を連れてひんぱんに会食しました。また、学会本部や聖教新聞社等の専用室で、「出張天ぷら、出張すし」をふるまわれることも何度もあったようです。

ただ、東西哲学書院の篠原善太郎社長（戦前は「河田清」のペンネームを持つ作家でもありました）は、死の直前には池田のそういう態度に対して批判的であったといいますがね。

とにかく、池田の好物は、トロに天ぷら、中華料理、すき焼き、すし。そしてデザートには高級メロンを食しました。見るも豪華な食卓ですね。けれどもそれがゆえに、晩年は糖尿病に苦しんでいたといいます。

せっかくの宗教家も、食の欲望には耐えられなかったというところでしょうか。
