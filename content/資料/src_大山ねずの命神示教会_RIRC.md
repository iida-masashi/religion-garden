| 教団・団体の主な沿革 |  | 
| 昭和21年11月15日、大山ねずの命は、一人の赤子に神の御魂を封じ込め、この世に降臨された。森日出子と名付けられたその御子は、後に大山ねずの命直々の使者、供丸姫（ともまるひめ）先生となり、神の化身と明かされる。 この神の降臨と同時期、不治の病に苦しむ稲飯定雄（いないさだお）氏は、夢に現れた大山ねずの命に命を救われた。その後、昭和23年9月23日、再び神が現れ、使者供丸斎（ともまるさい）として、人々を救済する任を命じられる。そして、5年間、神のご教育を受け、昭和28年9月23日に大山ねずの命神示教会を、横浜市西区戸部町に設立。 一方、成人した供丸姫先生は、供丸斎先生に命を救われ、昭和42年から神の道へ。昭和50年7月1日「副使者」に、昭和60年9月23日「使者」に、昭和61年9月23日「直使」にと歩みを進め、昭和62年11月15日にその正体は神の化身と明かされた。併せて、神示教会の本部を、供丸姫先生ご生誕、すなわち神の降臨の聖地、横浜市南区宮元町に移して、「神総本部（しんそうほんぶ）」とした。 供丸姫先生に神の御魂が封じ込められた事実が明かされたことにより、人類が確実に救われる手だて、「希望の光（みち）」が確立。それを見届けられた供丸斎先生は、神から託された任を果たし、昭和63年10月29日に、大山ねずの命の側近の神、代神供丸斎命（だいしんともまるさいのみこと）として昇華された。 「希望の光（みち）」が開かれ、信者が爆発的に増える中、供丸姫先生は神示を基に数々の真理を表され、さらに救いの道を確かなものとされていった。同時に、全国各地に布教所、偉光会館（ひかりのやかた）の建設を進めた。さらには、各地に納骨施設も創設。これにより、誕生から人生の終焉（しゅうえん）まで、そして代を超えても末永く救われる環境が整う。こうして確かな救いの道が完成して、平成14年9月17日、供丸姫先生は神魂（しんこん）として神の世界へ戻られた。 今は、使者の任にある供丸光（ともまるこう）先生が、神示を受けられ、信者を導かれている。そこには、希望の光（みち）を通す生き方が示され、神示に沿って生きれば、必ず満ち足りた悔いのない人生が歩み抜けるようになっている。 現在、横浜市南区宮元町に神総本部、そして全国に偉光会館が38カ所開設され、いつでも参拝、授業、儀式、相談などが可能である。また、海外にも、令和3年に北米事務所を開設。納骨施設は、神総本部の付帯施設として神奈川県湯河原町に開設された偉光郷（ひかりのさと）を中心に、全国に13カ所備えている。 |  |

| 教団・団体の活動 |  | 
| 活動の趣旨 | 当教会は、実在の神が、人類の救済を目的として設立された神の教会であり、この世の仕組み、真理と、人としての正しい生き方を表し、人間を真実の幸福へと導く教会である。 | 
| 家庭での信仰活動 | 神の教えを学び、それを心の指針として、家族が互いに支え合い、和のある家庭を築けるように、祈願しながら取り組む。神、仏、人への礼の心、感謝や反省、報恩の思いを持って､心の安定と向上を図る。親、先祖、家族や支えてくれる周りの人々に、感謝と報告を忘れず、安心感を与える。 | 
| 教団施設での活動 | 折に触れて、神総本部、全国各地の偉光会館（ひかりのやかた）に足を運び、神が表される教えを学ぶ。その中から気付いたことを、祈願しながら実践に移し、自身の心の成長を図る。教えの生かし方を確認したいときや、深い悩みが生じたときなどは、教務相談（無料）を受けられる。併せて、人生のさまざまな節目に、儀式を通して神のご守護を受ける。 |
