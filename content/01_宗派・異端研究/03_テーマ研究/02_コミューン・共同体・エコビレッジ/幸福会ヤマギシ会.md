# 幸福会ヤマギシ会 専門構造分析ノート

> [!summary] 要旨
> 幸福会ヤマギシ会（通称：ヤマギシ会、ヤマギシズム）は、山岸巳代蔵（1901-1961）が1952年に創立し（Wikipedia「山岸巳代蔵」による。1953年に「山岸式養鶏会」として発足したとする説もあり、§12留保13参照）、1995年に現名称へ変更した農業共同体である。「無所有一体（無所有・共用・共活）」を中核理念とし、私有財産の概念を否定して「全人幸福社会の実顕」を目指す。全国の「実顕地」と呼ばれる拠点で共同生活・農業を営むが、1990年代半ばに子どもへの処遇や勧誘手法を巡って社会問題化し、複数の脱会者訴訟・国税局の追徴課税を経験した。宗教法人ではなく、公式サイトも特講について「教える人はいません。宗教ではありません」と記している（公式サイトで確認）。

---

## 1. 命題の構造（通説・周辺文化 vs 対象自体の独自性）

幸福会ヤマギシ会は他の新宗教・宗教法人からの分派ではなく、思想家・山岸巳代蔵が独自に提唱した「ヤマギシズム」に基づく独立系の農業共同体である。宗教法人格を持たず、公式に「宗教ではない」と自称している点が他教団と大きく異なる。他教団との系譜上の比較対象がないため、本節は周辺の共同体運動との対比にとどめる。

| 比較考察軸 | 周辺の共同体運動一般 | 幸福会ヤマギシ会 |
| :--- | :--- | :--- |
| **信仰対象** | 教義・信仰対象を持つ場合が多い | 特定の信仰対象なし（「ヤマギシズム」という思想・生活理念） |
| **創始者・理念形成の経緯** | 宗教的天啓に基づく場合が多い | 山岸巳代蔵が養鶏技術の研究・普及活動から「無所有一体」の思想を発展 |
| **系譜上の関係** | 母体教団からの分派が多い | 独立系（他教団からの分派ではない） |
| **法人格** | 宗教法人格を持つ場合が多い | 法人格を持たない任意団体的性格＋実顕地ごとの農事組合法人（宗教法人ではない） |
| **財産観** | 私有財産を前提とする場合が多い | 私有財産の全否定（参画時に財産の「無条件委任」） |

## 3. 創始者と理念・起源

山岸巳代蔵は滋賀県蒲生郡老蘇村（現・近江八幡市）の出身で、1922年より養鶏を中心に農業を始めた篤農家であった。1950年のジェーン台風の際に山岸の田地が無事だったことが注目され、以後講演活動を始めた。鶏糞による米の増産と鶏卵の増産を目指す実践の中から、所有の概念を全否定する「無所有一体」の思想を形成し、1952年にその社会活動実践母体として山岸会を創立した（Wikipedia「山岸巳代蔵」による。Wikipedia「幸福会ヤマギシ会」は1953年に山岸式養鶏会として発足し約10日後に山岸会へ改称と記しており、発足年には両説がある。§12留保13参照）。1956年には第1回の特別講習研鑽会（特講）が開かれ、同年・翌年の参加者はあわせて4,500名を超えたという（Wikipedia）。

宗教的な天啓や神格化された教祖像ではなく、農業技術の「秘匿公開」を入口としながら精神論を説く独特のスタイルが取られた点が、他の新宗教の創始者像と異なる。

## 4. 沿革・歴史変遷

- 1952年: 山岸巳代蔵が山岸会を創立（Wikipedia「山岸巳代蔵」）。なおWikipedia「幸福会ヤマギシ会」は1953年に「山岸式養鶏会」を発足し約10日後に「山岸会」に改称したと記す（発足年は両説あり、§12留保13参照）。
- 1956年: 第1回ヤマギシズム特別講習研鑽会（特講）を開催。
- 1958年: 「百万羽科学工業養鶏」構想を発表。三重県伊賀町（現・伊賀市）に春日山実験地が発足。
- 1959年7月: 特講受講者の監禁・強制受講の疑いで幹部12名が監禁・脅迫容疑で逮捕される（山岸会事件）。マスコミで大きく報道された。
- 1961年5月4日: 山岸巳代蔵が死去（クモ膜下出血）。指導は杉本利治が引き継いだ。
- 1970年代: 「自然食品を生産するコミューン」として再注目され、流通体制を整備。経済規模が拡大。
- 1980年代: 子育て・教育への関心を背景に支持が広がり、1983年から1990年にかけて10の社会実顕地が新設された。実顕地参画者は1984年の740名（子供を除く）から1995年には2,270人に増加（Wikipedia）。
- 1994年: 元参画者が「ヤマギシを考える全国ネットワーク」を結成し、会の負の側面を告発。メディアの批判的報道が続出した。
- 1995年: 「幸福会ヤマギシ会」に改称。同年以降、脱会者による寄進財産返還請求訴訟が10件以上提起され、「マインドコントロール」的手法が主張された。
- 1997年: 国税局の税務調査により、約200億円の申告漏れを理由に約60億円の追徴課税を受ける。
- 1998年以降: 「村から街へ」の方針で40歳以上の参画者を外部社会へ送り出すなど縮小・内閉の動き。参画者は1999年の約2,150名から2001年1月には約1,700名（子供を除く）へ減少（Wikipedia、近藤衛の分析）。
- 2004年2月25日: 東京地方裁判所が平成13年（ワ）第19650号損害賠償請求事件で判決。ヤマギシズム生活実顕地調正機関に対し、原告6名への計3,620万円（600万円・100万円・850万円・170万円・1,500万円・400万円）および平成13年11月2日から年5分の割合による遅延損害金の支払いを命じ、第1次的請求・その余の第2次的請求並びに農事組合法人（被告法人）に対する各請求はいずれも棄却した（判決文で確認、src_幸福会ヤマギシ会_東京地裁判決文）。
- 2020年代: 実顕地は国内26箇所・海外6箇所、共同生活者は約1,500人規模（Wikipedia）。

> [!warning] 社会問題化の経緯
> 1990年代半ばの社会問題化については、ジャーナリスト・米本和広の著書『洗脳の楽園』（宝島社）等の調査報道が知られる。訴訟については、東京地裁平成13年（ワ）第19650号事件の判決文（平成16年2月25日言渡）を2026-11-18に一次資料として取得し、主文・認定事実を確認した（src_幸福会ヤマギシ会_東京地裁判決文）。その他の訴訟および税務調査の詳細は、なおWikipedia・二次資料に基づく。

## 5. 理念・実践の深層解剖

### 5-1. 無所有一体
私有財産の概念を否定し、土地・生産手段・収益等を実顕地の共同体で一体的に所有・運用する思想。「無所有・共用・共活」の三位一体で表現される。実顕地への参画者は私有財産のすべてを会に「無条件委任」し、実顕地内では貨幣が流通せず、労働への賃金も支払われない（帳簿上は賃金が計上される）生活が営まれる（Wikipedia）。

### 5-2. 全人幸福社会の実顕
個人の幸福と社会全体の調和を同時に実現することを目指す。会は自らの世界変革を「急進Z革命」（頭脳革命）と称する（Wikipedia、米本和広・近藤衛の取材に基づく記述）。

### 5-3. 研鑽会と特講
意思決定は「研鑽」と呼ばれる話し合いによって行われる建前であり、1週間の合宿形式の入門講座「ヤマギシズム特別講習研鑽会（特講）」を受講すると会員となり、さらに2週間の「研鑽学校」を経て実顕地に参画する資格を得る。特講が7泊8日で「一生に一度しか参加できない」こと、研鑽学校が14泊15日であること、参画時に全財産の引き渡しと返還請求の放棄を内容とする誓約書を差し入れることは、東京地裁の判決文の認定事実でも確認できる（src_幸福会ヤマギシ会_東京地裁判決文）。宗教学者の島田裕巳は特講をイニシエーションの機会と位置づける一方、米本和広・近藤衛らは反復質問による変性意識・解離の危険を指摘し、精神科医の斎藤環も解離性症状との類似を報告している。評価は研究者・体験者間で分かれており、中立的に併記する。

### 5-4. 組織の実態を巡る見解
会は「全体を統率する特定の個人・集団は存在せず、本部も連絡機関にすぎない」と説明する。他方、米本和広は豊里実顕地に「ヤマギシズム生活実顕地調正機関本庁」が置かれ、他の実顕地がその決定に従う中央集権的構造を取材に基づき指摘している。両論を併記する。なお東京地裁の判決文は、調正機関を「ヤマギシ会に参画した構成員の集合体」であり法人格を有しない権利能力なき社団と認定し、平成10年当時、全国39箇所・海外7箇所の実顕地の活動主体であったとしている。また同判決文によれば、農事組合法人（被告法人）は昭和44年に調正機関が農業協同組合法に基づいて設立した法人で、大安・美里・内部川・一志・明和・豊里の6実顕地の土地・建物・生産財を所有し、その産業経済活動の法的主体となっている（src_幸福会ヤマギシ会_東京地裁判決文）。

## 6. 宗教学的・歴史社会学的意義

- 宗教法人格を持たず「宗教ではない」と自称しながら、私有財産の全否定・共同生活・イニシエーション的講座（特講）という宗教的共同体に類似した構造を持つため、新宗教研究・ユートピア共同体研究の双方で扱われる。
- 売上高では農事組合法人のトップに位置するとされ（Wikipedia）、「エコビレッジの先駆者」として評価されることもある一方、1990年代にはカルト批判の対象となった。評価の振幅自体が、日本の共同体運動史を考える素材となる。
- 島田裕巳（宗教学）、鶴見俊輔・本多勝一（肯定的評価）、米本和広・近藤衛・斎藤貴男（批判的取材）等、論者による評価が大きく分かれる対象である。

## 7. 拠点・現地情報

- **豊里実顕地**: 三重県津市。最大の実顕地で、調正機関本庁が置かれるとされる。運営法人はヤマギシズム生活豊里実顕地農事組合法人（法人番号3190005000255、津市高野尾町5010番地）。
- **春日山実顕地**: 三重県伊賀市。1958年に実験地として発足した最古級の実顕地。
- **東京案内所**: 東京都町田市忠生2-29-18（多摩実顕地・ファーム町田店の隣接地）。かつて新宿区高田馬場等にあった案内所が2021年5月に移転したものとされる（旧稿の二次資料確認に基づく）。
