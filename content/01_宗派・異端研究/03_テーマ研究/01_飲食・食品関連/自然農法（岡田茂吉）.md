# 自然農法（岡田茂吉） 教理・実践専門構造分析ノート

> [!summary] 要旨
> 自然農法は、[[世界救世教]]創始者・[[岡田茂吉]]が1930年代に開始した無農薬・無肥料栽培の研究に起源を持つ農業思想・実践である。年表の中核（1936年2月研究開始・1950年名称統一）はWikipedia「岡田茂吉」「自然農法」の両記事で確認できる。「肥毒」概念は両記事の本文に現れないが、（公財）自然農法国際研究開発センターの機関誌が岡田の『無肥料栽培』に基づく用語として明記していることを再検証（2026-11-16）で確認した。岡田没後は、比嘉照夫の微生物資材「EM菌」を取り入れるか否かを巡って流派が分岐したとされるが、EM菌関連の経緯には未検証部分が残る。EM菌自体はWikipedia「EM菌」において疑似科学との批判が明記されている。

## 3. 起源と設立の経緯

- 岡田茂吉は無農薬・無肥料の栽培研究を開始し、1942年からは米・水稲・小麦・大豆等の無肥料栽培を研究した（Wikipedia「岡田茂吉」）。
- 1948年に論説文『無肥料栽培』を発表し、1950年に名称を「自然農法」に統一した（Wikipedia「岡田茂吉」）。
- 基本理念として「土が本来持つ能力を発揮させる」ことが説かれたとされる（Wikipedia「自然農法」「岡田茂吉」の記述ベース）。

## 5. 教理・実践の深層解剖

### 5-1. 確認できる基本原理
- 無農薬・無肥料を基本とし、土本来の生育力を活かす栽培を目指す点は、Wikipedia両記事の記述で確認できる。

### 5-2. 流派の分岐（二次情報ベース）
岡田茂吉没後、実践スタンスは「資材（EM菌等）を導入するか否か」を軸に分岐したとされる。

| 流派 | スタンス（二次情報ベース） |
| :--- | :--- |
| **EM活用派（EM自然農法等）** | 微生物資材（EM菌）を土壌活性化の補助手段として活用 |
| **秀明自然農法** | 外部資材を投入せず、落葉・枯れ草の自然堆肥と自家採種で実践（[[MIHO MUSEUM レストラン「ピーチ」（秀明自然農法）]]等） |
| **MOA自然農法** | 完熟堆肥の使用基準をガイドライン化し、検定・認証制度を通じて体系化 |
| **TOREK自然農法** | [[東京黎明教会]]系。無施肥無農薬を徹底（地下カフェ[[SUZU COFFEE（東京黎明アートルーム・自然農法カフェ）]]で提供） |

### 5-3. EM菌を巡る科学的評価・疑似科学批判
- 日本語版Wikipedia「EM菌」記事は、EM菌を「疑似科学的理論に基づいた」微生物資材と明記し、理論の整合性や効果検証の不備を指摘している（[[src_EM菌_Wikipedia]]で確認）。
- 放射能除去等の一部効果主張への批判も同記事に記載されている。
