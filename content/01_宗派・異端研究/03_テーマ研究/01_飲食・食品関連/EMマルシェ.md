# EMマルシェ 専門構造分析ノート

> [!summary] 要旨
> EMマルシェ（em-marche.jp）は、EM（有用微生物群）を用いて栽培された農産物（「EM育ちの農産物」）の生産者を紹介し、各生産者の直販へつなぐウェブサイトである。サイトの自己紹介は「EM育ちの農産物って、おいしい！元気になれる！だけど、どこで買えるの？ EMマルシェは、そんな皆さんの声から生まれました」とし、「一般流通にはほとんど乗らない貴重なEM育ちの農産物と、まごころを込める生産者さんに、もっともっと多くの皆さんが出会ってほしい」と掲げる。掲載生産者の一例である「じょーじ農園」（愛知県日進市）は株式会社EM生活が運営母体であり、野菜セットの注文は農園自身の公式LINEショップで受け付けるなど、販売は生産者側のチャネルで行われる形態が確認できる。サイト自体の運営会社の公式表示（特定商取引法に基づく表記等）は本調査では取得できなかった（§12）。

## 3. 起源と成立の経緯

- サイトのトップページは、EM育ちの農産物の購入先が分からないという消費者の声に応えて生まれたと自己紹介している。
- 開設時期・開設主体を明示する公式ページは、本調査では確認できなかった。
- EMグループの流通体制では、卸販売を株式会社EM生活、小売の通信販売をEM生活通販株式会社が担うとされており（EMグループ公式「エコライフ事業」）、EMマルシェはこのEM生活系の流通の一角に位置するとみられるが、サイトと両社の関係を明示する公式資料は確認できなかった（§12）。

## 5. 内容・様式の深層解剖

### 5-1. サイトの仕組み
- トップページでは生産者と農産物が紹介され、各生産者のページに栽培方針、農産物ラインナップ、価格、送料、注文方法が掲載される。
- 注文は生産者自身のチャネルで行われる事例が確認できる（じょーじ農園は公式LINEショップで注文を受け付け、クレジットカード決済・銀行振込・代引きに対応するとしている）。EMマルシェ自体が決済を担うかどうかは、生産者により異なる可能性があり、本調査では確定できなかった。

### 5-2. 取扱品目の範囲
- 中心はEM栽培の生鮮農産物である。確認できる例として、野菜セット（じょーじ農園）、さつまいも（熊本県の生産者「工藤さん」）、米（関農園、新潟県南魚沼）、有機JAS認定のみかん（有田みかん）がある。
- EM・1やEM発酵食品等のEM商品全般を扱うEM生活公式オンラインショップ（em-seikatsu.co.jp）とは異なり、EMマルシェは農産物と生産者の紹介に特化した構成である。

### 5-3. じょーじ農園（掲載生産者の一例）
| 項目 | 内容 |
| :--- | :--- |
| **所在地** | 〒470-0125 愛知県日進市赤池5丁目1703番地 |
| **代表者** | 岩瀬尉司 |
| **運営母体** | 株式会社EM生活（愛知県名古屋市） |
| **規模** | 約3反（0.3ヘクタール）、少量多品目栽培 |
| **栽培条件** | 農薬・化学肥料不使用。肥料はEMボカシ・EM発酵堆肥、栽培時の使用材料はEM活性液・EMセラミックス・EM木炭・天然ミネラル・にがり |
| **EM使用歴** | 前身の農体験塾の農地として10年以上EMを使用。じょーじ農園としては2021年から |
| **商品例** | 季節野菜セットM 2,000円／L 3,000円（いずれも税別・送料別）。にんじん、さつまいも（紅はるか）、新玉ねぎ等の単品販売もある |
| **販路** | 公式LINEショップによる全国発送のほか、名古屋市内のレストランや産直市場へ朝採れ野菜を直接配達するとしている |

### 5-4. その他の掲載生産者
- 工藤さんのさつまいも（熊本県）：紅はるかを販売（トップページ掲載）。
- 関農園（新潟県南魚沼市）：EMを用いる米農家として取材記事が掲載され、2024年にはNHK番組への出演がサイトで告知された。
- 掲載生産者の全数と一覧は、本調査では取得できなかった（§12）。

### 5-5. EMグループの流通体制との関係
- EMグループ公式の「エコライフ事業」ページによれば、流通は次の体制である。卸販売（販売店支援）は株式会社EM生活が担い、全国の販売店へEM商品やEM農産物を提供する。小売の通信販売はEM生活通販株式会社が担い、電話やインターネットで注文を受ける。店舗販売は「暮らしの発酵ストア」3店舗（沖縄県北中城村、愛知県名古屋市、神奈川県鎌倉市）が担う。
- したがって、EM農産物の実店舗での購入先はEM生活の販売店網と暮らしの発酵ストアであり、EMマルシェはこれらとは別に、個別生産者の直販を紹介するオンラインの受け皿として機能している。
- [[みろく菜園]]（ミロクコミュニティ救世神教の農園ネットワーク）の生産物がEMマルシェで扱われているかは、本調査では確認できなかった。また、EMグループの直営農場である沖縄のサンシャインファーム（EMウェルネス「暮らしの発酵ライフスタイルリゾート」の食材供給農場）の生産物について、EMグループ公式は「ホテル内で提供されたり、沖縄県内外に販売されたりしています」とするが、EMマルシェでの取扱いは確認できなかった。

## 6. 学術的・社会学的意義

- EMマルシェは、微生物資材の普及組織が、その資材を用いる生産者の「出口」（販路）を情報基盤として用意した事例である。資材の供給（EM生活による卸販売）と農産物の流通支援が同じ企業グループ内で連動している。
- 生産者の顔と栽培方針を前面に出し、購入を生産者自身の直販へつなぐ形式は、一般の産直ECと共通するが、共通項が「EM栽培」という技術ブランドである点に特徴がある。
