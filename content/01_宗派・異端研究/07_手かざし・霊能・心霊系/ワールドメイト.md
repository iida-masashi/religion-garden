# ワールドメイト 専門構造分析ノート

> [!summary] 要旨
> ワールドメイト（旧称：コスモコア→コスモメイト→パワフルコスモメイト）は、1984年（昭和59年）12月に深見東州（本名：半田晴久）と植松愛子（旧名：橘カオル）によって創始された神道系の新宗教団体。深見東州は幼少期に世界救世教、青年期以降に大本の教義を研究し、両者の霊学思想を再構成する形で独自の教義体系を築いた。教祖・深見東州は予備校「みすず学苑」や旅行会社「ジャパンペガサスツアー」等を運営する実業家であり、オペラ歌手・書家・画家としても活動する。ギャグやダジャレを取り入れた「エンターテインメント性」と、関連旅行会社を通じた全国神社・霊山・伊豆総本部（皇大神御社）への大規模な**「神事団体参拝バスツアー」**を特徴とする。2012年9月12日に宗教法人として認証された。

## 3. 団体参拝（神業参拝・ツアー）の構造と特色

ワールドメイトは、新宗教の中でも**独自の団体参拝システム（神業参拝・ツアー）**を確立している。

### 3-1. 直営旅行会社（ジャパンペガサスツアー）による一括手配
教祖・深見東州（半田晴久）自身が代表取締役社長を務める旅行会社**「株式会社ジャパンペガサスツアー（JPT）」**が専属で移動・宿泊・参拝バスを手配している。会員向けの神事、総本部（皇大神御社）参拝、全国著名神社への参拝ツアーの交通インフラを自グループ内で内製化・システム化している。

### 3-2. 神事（大神業）と全国神社・パワースポット巡拝
年間を通じて開催される「神事（大神業・神業）」の際、数千人〜数万人規模の会員が参拝ツアーに参加する。
* **総本部「皇大神御社」参拝**（静岡県伊豆の国市）：教団総本部・神殿への参拝。
* **全国著名神社・霊山参拝**: 鹿島神宮・香取神宮（要石・武神）、伊勢神宮（元津神）、富士山・阿蘇山・箱根等の霊山や主要神社への祈祷・参拝ツアーが企画・運行される。

### 3-3. エンターテインメントと参拝の融合
従来の伝統的宗教（天理教や金光教など）の厳粛・禁欲的な団体参拝とは異なり、深見東州のコスプレ・ギャグ・大講演会、野外ステージイベント（「明るく楽しい神事」）と、神社参拝・大祓祈願がセットになった「エンターテインメント型参拝ツアー」として展開される。

## 4. 歴史変遷クロノロジー

```
・1951年3月18日: 深見東州（本名・半田晴久）、兵庫県西宮市に誕生。
・1972年: 植松愛子（旧名・橘カオル）に「スの神」降臨の啓示。
・1978年: 「深見青山」名義で著作刊行開始、みすず学苑の運営開始。
・1984年12月: 「コスモコア」設立。
・1987年: 「皇大神社」に改称、「コスモメイト」通称使用開始。ジャパンペガサスツアー等の関連事業を開始。
・1988年: 皇大神御社（静岡県伊豆の国市）を建立し総本部に定める。
・1994年12月: 「ワールドメイト」に改称。
・2006年5月25日: 東京高裁、脱税疑惑に関する課税処分取消訴訟でワールドメイト側勝訴が確定。
・2012年9月12日: 野田内閣（第2次改造）の平野博文文部科学大臣により宗教法人として認証。
・2019年1月: 信者数約82,000人（公式サイト）。
```
