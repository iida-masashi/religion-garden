# ワールドメイト 専門構造分析ノート

> [!summary] 要旨
> ワールドメイト（旧称：コスモコア→コスモメイト→パワフルコスモメイト）は、1984年（昭和59年）12月に深見東州（本名：半田晴久）と植松愛子（旧名：橘カオル）によって創始された神道系の新宗教団体。教祖・深見東州は予備校「みすず学苑」や、**観光庁長官登録第1種旅行業者である「ジャパンペガサスツアー株式会社」**の代表取締役社長を務める実業家であり、オペラ歌手・書家・画家としても活動する。自グループ内に第1種旅行会社を所有し、全国神社・霊山・伊豆総本部（皇大神御社）への大規模な**「神事団体参拝バスツアー」**や海外要人招聘の渡航手配を内製化している点が、日本の宗教界において極めて異例な構造として特筆される。2012年9月12日に宗教法人認証。

## 3. ジャパンペガサスツアー（JPT）の深掘り分析

日本の新宗教において、教祖・代表者自身が政府登録の**「第1種旅行業者」**を所有・運営する構造は極めて稀有である。

### 3-1. 企業概要と基本スペック
* **正式社名**: ジャパンペガサスツアー株式会社（JAPAN PEGASUS TOUR CO., LTD.）
* **代表取締役社長**: 半田晴久（深見東州）
* **設立年月日**: 1982年（昭和57年）8月23日（1982年10月2日登録）
* **登録番号**: **観光庁長官登録旅行業第626号（第1種旅行業者）**
* **本社所在地**: 東京都杉並区西荻南2丁目（みすず学苑・たちばな出版・ワールドメイト東京拠点と同地区）

### 3-2. 役割と3大機能
1. **会員向け「神事（大神業）参拝ツアー」の手配**:
   - 静岡県伊豆の国市の総本部「皇大神御社」参拝のほか、鹿島神宮・香取神宮・伊勢神宮や全国の霊山（阿蘇山・富士山・箱根等）への大型参拝バスツアーを一括手配。
   - 海外での神事参拝・霊場巡拝における航空券・ホテル手配。
2. **ISPS等の国際イベント・海外要人招聘の渡航アテンド**:
   - 深見東州が率いるNPO法人「国際スポーツ振興協会（ISPS）」や「世界開発協力機構（WSD）」が主催する国際ゴルフ大会・ブラインドゴルフ・スポーツイベントの手配。
   - イギリスのボリス・ジョンソン元首相、トニー・ブレア元首相、ヘンリー王子、オバマ元米大統領ら海外VIPの日本招聘・アテンドにおける移動インフラ。
3. **一般旅行業務と収益事業**:
   - 一般顧客向け格安航空券・パッケージツアー・ビジネス出張手配の提供。

### 3-3. 宗教学・経営学的意義（インフラの内製化）
多くの新宗教（天理教、創価学会など）がJTBや日本旅行等の大手旅行会社へ受託委託したり窓口提携を結ぶのに対し、ワールドメイト（深見東州）は第1種旅行会社を自前で所有することで、**「大規模参拝の輸送手数料・粗利のグループ内循環」「宗教法人名義を前面に出さない一般企業名義での柔軟な取引」「海外要人招聘の迅速な渡航手配」**という3つの戦略的メリットを享受している。

## 4. 歴史変遷クロノロジー

```
・1951年3月18日: 深見東州（本名・半田晴久）、兵庫県西宮市に誕生。
・1972年: 植松愛子に「スの神」降臨の啓示。
・1978年: みすず学苑の運営開始。
・1982年8月23日: ジャパンペガサスツアー株式会社設立（10月2日 観光庁長官登録第1種旅行業者登録）。
・1984年12月: 「コスモコア」設立。
・1987年: 「皇大神社」に改称、「コスモメイト」通称使用開始。
・1988年: 皇大神御社（静岡県伊豆の国市）を建立し総本部に定める。
・1994年12月: 「ワールドメイト」に改称。
・2006年5月25日: 東京高裁、脱税疑惑に関する課税処分取消訴訟でワールドメイト側勝訴確定。
・2012年9月12日: 宗教法人として認証。
・2019年1月: 信者数約82,000人（公式サイト）。
```
