# 神智学協会 専門構造分析ノート

> [!summary] 要旨
> 神智学協会（The Theosophical Society）は、[[H.P.ブラヴァツキー]]夫人（1831-1891）と[[H.S.オルコット]]大佐（1832-1907）が1875年にニューヨークで設立した国際的オカルティズム・霊智思想団体である。東洋の古代叡智（ヒンドゥー教・仏教・秘教思想）と西洋の神秘主義を統合し、日本の新宗教や霊性思想家（浅野和三郎、鈴木大拙、大本等）にも多大な影響を与えた。

## 3. 沿革

1875年にニューヨークで結成され、後にインドのアディヤールに国際本部を移転。日本へは明治期にオルコット大佐が来日し仏教界に熱狂的に迎えられた。大正・昭和・平成を通じて翻訳文献が刊行され、心霊主義や精神世界運動の理論的基盤となった。

## 4. 歴史変遷クロノロジー

```
・1875年: ニューヨークにて神智学協会創立
・1879年: 国際本部をインドへ移転
・1889年: オルコット大佐が来日、全国で講演
```
