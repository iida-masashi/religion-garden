# 霊波之光 専門構造分析ノート

> [!summary] 要旨
> 霊波之光（れいはのひかり）は、[[波瀬善雄]]（本名・波瀬敬介、信徒から「御守護神様」と尊称、1915-1984）が1954年（昭和29年）に立教した新宗教教団である。千葉県野田市山崎に広大な総合本部境内を構え、「人類救済と世界平和の実現」を掲げて御神光による病気平癒や幸福祈願の実践を行っている。

## 3. 創始者と沿革

波瀬善雄は厳しい修行と天啓を経て、1954年に「霊波之光」を立教。千葉県野田市に広大な境内地を拓き、巨大な礼拝堂や平和の塔を建立した。

---

## 4. 歴史変遷クロノロジー

```
・1957年: 宗教法人認証取得
・1984年: 初代・波瀬善雄死去、第2代・波瀬敬敬が継承
```

## 5. 教理・儀礼の特色

- **霊波による救済**: 御守護神様を通じて放射される霊波（御神光）により、運命を好転させ病苦から救われると説く。
