# PL病院 カフェレストラン（パーフェクト リバティー教団）

> [!summary] 要旨
> **PL病院 カフェレストラン**は、大阪府富田林市の総合病院「PL病院」（運営：医療法人宝生会）内に設けられた飲食施設である。病院公式サイトのフロアマップ（2026-11-15取得）によれば、病院2階に「喫茶・食堂、コンビニ、情報コーナー」が配置されている。PL病院はパーフェクト リバティー教団（PL教団）の関連医療法人が運営する病院で、その起源は1933年の「ひとのみち教団医学研究所」に遡り、1956年11月1日に富田林市で「宝生会病院」として開設、1970年に富田林市の要請で市民に開放され「PL病院」に改称した（病院公式サイト「病院概要・沿革」）。病院理念は教団の根本理念を引く「人生は芸術である 医療もまた芸術である」。なお旧稿にあった運営法人名「医療法人精和会」、所在地「富田林市廿山2-1-36」、「1970年代開院」の各記述は公式資料と異なる誤りであり、本照合で訂正した（詳細は§12）。

## 3. 起源と成立の経緯

PL病院の起源は、PL教団の前身である「ひとのみち教団」が1933年に大阪府布施（現・東大阪市）に設けた「ひとのみち教団医学研究所」にある（病院公式サイト「病院概要・沿革」）。1955年に医療法人宝生会が設立され、1956年11月1日、富田林市に「宝生会病院」（86床）が開設された。これが現在のPL病院の直接の前身である。

院内の飲食施設がいつ設置されたかについては、公式資料に明記がなく未確認である（§12）。ただし病院という施設の性質上、食堂・売店は開設以来の付帯機能として存在してきたとみられるが、これは推測であり本ノートでは確定情報として扱わない。

## 4. 変遷・歴史

病院公式サイト「病院概要・沿革」に基づく病院本体の変遷は以下の通りである。

| 年 | 出来事 |
| :--- | :--- |
| 1933年 | 前身「ひとのみち教団医学研究所」を布施に設立 |
| 1955年 | 医療法人宝生会を設立 |
| 1956年11月1日 | 富田林市に宝生会病院を開設（86床） |
| 1970年 | 富田林市の要請により市民に開放し、「PL病院」に改称 |
| 2006年 | 新病院が現在地（富田林市新堂）に竣工 |

教団施設群の飲食機能としては、遊園地「PLランド」（1957年開園）が園内に飲食施設を備えていたが、1989年9月に完全閉園した（Wikipedia「PLランド」）。

運営母体であるPL教団については、照合済みの[[パーフェクトリバティー教団]]ノートにより、第3代教祖・御木貴日止が2020年12月5日に死去した後、その夫人・御木美智代が教主代行を務め、2026年2月22日に第4代教祖に就任したことが確定している。

## 5. 内容・様式の深層解剖

- **施設構成**: 公式フロアマップ（2026-11-15取得）では2階に「喫茶・食堂、コンビニ、情報コーナー」がまとめて配置されており、診療・健診の待ち時間に食事・休憩・買い物ができる複合アメニティ空間となっている。
- **理念との接続**: 病院理念「人生は芸術である 医療もまた芸術である」は、PL教団の根本理念「人生は芸術である」を医療に適用したもので、食堂を含む院内環境全体がこの理念の下に位置づけられている。
- **具体的なメニュー**（モーニングセット、日替わり定食、麺類等）は旧稿に記載があったが、公式サイト等の一次情報では確認できなかったため、本照合では未検証として分離した（§12）。

## 6. 学術的・社会学的意義

- **宗教都市の生活インフラ**: PL教団は富田林市に大本庁、大平和祈念塔、PL学園、ゴルフ場、かつての遊園地PLランド等を配置する大規模な施設群を形成した。病院とその院内飲食は、宗教施設群が教育・医療・レジャーまでを内包する「複合都市」として機能してきたことを示す一例である。
- **地域医療への開放**: 1970年に市の要請で市民へ開放され教団名を冠したまま地域の中核病院となった経緯は、新宗教系医療法人が公共的医療インフラとして地域社会に組み込まれた事例として位置づけられる。
