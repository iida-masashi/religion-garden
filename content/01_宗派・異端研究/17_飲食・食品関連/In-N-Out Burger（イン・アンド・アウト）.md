# In-N-Out Burger（イン・アンド・アウト）専門構造分析ノート

> [!summary] 要旨
> **In-N-Out Burger（イン・アンド・アウト・バーガー）**は、1948年にハリー・スナイダーがカリフォルニア州ボールドウィン・パークに開業したハンバーガーチェーンである。創業家のキリスト教信仰を背景に、飲料カップの底・包装紙等に聖書の章節参照（「ヨハネ 3:16」「箴言 3:5」等）が印刷されていることで知られる。この慣行は1980年代に2代目リッチ・スナイダーのもとで始まった（Wikipedia）。本社はカリフォルニア州アーバインにあり、創業家による非上場経営を維持する。日本には常設店舗がなく、期間限定のポップアップ出店が報じられることがある。

## 3. 起源と成立の経緯

### 3-1. 1948年の創業とドライブスルー
In-N-Out Burgerは1948年、ハリー・スナイダーがカリフォルニア州ボールドウィン・パークに開業した。双方向スピーカーによるドライブスルー注文方式の先駆とされる。

### 3-2. 聖書の章節印刷の開始
包装等への聖句印刷は、ハリーの息子リッチ・スナイダー（Rich Snyder、1952-1993）が経営を担った1980年代に始まった。確認できる印刷箇所と聖句は次の通り（Wikipedia「In-N-Out Burger」の一覧による）。

| 印刷箇所 | 聖句 |
| :--- | :--- |
| 飲料カップ | ヨハネによる福音書 3:16 |
| ミルクセーキカップ | 箴言 3:5 |
| ハンバーガーの包装紙 | 箴言 24:16 |
| ダブルダブルの包装紙 | ナホム書 1:7 |
| フライドポテトの容器 | ルカによる福音書 6:35 |
| クリスマス期のカップ | 黙示録 3:20 |

章節番号のみが印刷され、本文は印刷されない。消費者は聖書を引かなければ内容を知ることができない「参照のみ」の表示形式である点が特徴的である。

## 4. 変遷・歴史

- 1976年：創業者ハリー・スナイダー死去。息子リッチが経営を引き継ぐ。
- 1980年代：聖句印刷を開始。
- 1993年：リッチ・スナイダーが飛行機事故で死去。兄ガイ、母エスターを経て経営が継承される。
- 2010年代：創業者の孫リンジー・スナイダーが株式の大半を取得し、オーナーとなる。
- 2020年代：本社機能の一部移転（ボールドウィン・パークへの集約）とテネシー州への東部展開が進められている（Wikipedia）。

---

## 5. 内容・様式の深層解剖

### 5-1. 「参照のみ」表示の構造
聖句の本文ではなく章節番号だけを示す形式は、信仰の押し付けを避けつつ、気づいた消費者に自発的な参照を促す穏当な信仰表示として分析できる。米国では、企業による宗教的メッセージの表示と消費者受容をめぐる事例として言及されてきた。

### 5-2. 未確認の印刷箇所
旧稿はホットココアのカップに「ヨハネ 13:34」が印刷されるとしたが、Wikipediaの一覧にはこの項目がなく、本照合では確認できなかった（未検証として分離）。

## 6. 学術的・社会学的意義

- 米国における「信仰を持つ企業（faith-based business）」の代表例の一つであり、宗教的アイデンティティを製品デザインに埋め込む手法の事例として、経営学・宗教学の双方から言及される。
- 創業家による非上場・同族経営の維持は、宗教的価値観と企業統治の関係を考える材料となる。
