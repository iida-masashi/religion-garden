# 真光正法之會 専門構造分析ノート

> [!summary] 要旨
> 真光正法之會（まひかりせいほうのかい）は、世界真光文明教団系の分派組織である陽光子友乃会から分派し、中野鷹照が初代会長となって1991年（平成3年）に設立された真光系宗教法人である。本部は埼玉県東松山市若松町の「主座主神神殿」。手かざしによる魂の浄化と「元還り」を説く。中野の死去（2002年）後は平澤秀周が会長として教団を運営している。

## 3. 創始者と天啓・社伝

創始者の中野鷹照は、かつて所属していた陽光子友乃会から分派する勢力からの要請に応じ、真光正法之會の初代会長となった（Wikipedia「真光正法之會」）。中野は、真光系諸教団の初代教え主である岡田光玉が神から託された「全人類総神の子への復活・元還り」を推し進めるとして会長に就いたとされる（教団側の位置づけとして記載する）。中野は2002年に死去し（Wikipedia「真光系諸教団」系譜表）、現在は中野の遺志を受け継いだ平澤秀周が教団を運営している。

## 4. 沿革・歴史変遷

```
・1991年（平成3年）: 中野鷹照が陽光子友乃会から分派し真光正法之會を設立
・1995年（平成7年）: 魁の主座（黄金神殿）を建立
・2001年（平成13年）: 宗教法人格を取得
・2002年: 中野鷹照死去。平澤秀周が継承
・2020年（令和2年）: 「主座主神神殿」を東松山市若松町2-6-48に建立し本部とする
```

## 5. 教理・儀礼・神観の深層解剖

- **教義**: 神の子として、本来の人のあるべき姿への「元還り」を目指し、「手かざし」により魂を浄化するとともに人格・品格・霊格を向上させ、神が目指している「地上天国」をこの世に顕現することの手伝いをするとしている（Wikipedia「真光正法之會」）。
- **神観**: 公式サイトは「天地創造の大元の主神」が地上に天国を造ることを祈り願っているとする。祭神は御親元主真光大御神。
- **祭祀・行事**（Wikipediaによる）：月始祭（毎月第1日曜日）、初級真光研修会（毎月3日間開催）、立春祭（2月4日）、周年大祭（8月）、大炎開陽霊祭（12月）。

---

## 6. 宗教学的・歴史社会学的意義

- 真光系の連鎖的分派の第3段階（世界真光文明教団→陽光子友乃会→真光正法之會）に位置し、分派側の幹部ではなく分派勢力の要請で外部から会長に就いたという継承形態が特徴とされる（Wikipediaの記述による）。
- 2020年に建立された主座主神神殿は、木造部と鉄筋コンクリート部を組み合わせた特異な外見の大建築で、講堂内部に小川が流れるなど凝った設備を持つとされ（Wikipedia）、真光系に共通する壮大な聖地建設への志向の一例である。
