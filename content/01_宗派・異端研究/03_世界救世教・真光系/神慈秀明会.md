# 神慈秀明会 専門構造分析ノート

> [!summary] 要旨
> 神慈秀明会（じんじしゅうめいかい）は、世界救世教の有力教会「秀明教会」を率いていた小山美秀子（1910-2003）が1970年（昭和45年）3月1日に独立・創立した単立宗教法人である。滋賀県甲賀市信楽町に聖地「神苑」と「MIHO MUSEUM」を構え、岡田茂吉の教えに基づく浄霊、秀明自然農法、美の創出を実践している。世界救世教の分派教団の中では最大規模の団体とされる。

## 3. 創始者と天啓・社伝

小山美秀子は1941年に岡田茂吉に入信し、世界救世教最大規模の「秀明教会」を築き上げた。岡田茂吉の死後、教団運営・教理解釈をめぐり教団本部と意見を異にし、1970年3月に教団を離脱・独立した。美秀子自身は教祖とはならず、死去していた岡田茂吉を神慈秀明会の教祖として立てた。

滋賀県信楽の山中に広大な聖地「神苑」を造成し、世界的建築家I.M.ペイ設計による鐘塔（カリヨン塔）、ミノル・ヤマサキ設計の教祖殿、および「MIHO MUSEUM」を開館させた。

## 4. 沿革・歴史変遷

```
・1941年: 小山美秀子、岡田茂吉に入信
・1952年: 秀明教会設立（法人の登記上の設立日は同年9月9日）
・1970年3月1日: 世界救世教から独立、「神慈秀明会」立教
・1983年: 信楽神苑に神殿・教祖殿が落慶
・1996年末: 「旧体制」から新体制へ移行（布教・献金方針の転換点とされる）
・1997年: MIHO MUSEUM開館
・2003年11月29日: 会主・小山美秀子死去
・2006年: 大阪国税局の税務調査で申告漏れ等が指摘される（§5-1）
・2022年: 小山弘子の逝去に伴い、小山玉男が3代会長に就任
```

## 5. 教理・儀礼・神観の深層解剖

- **純粋な浄霊の継承**: 岡田茂吉直伝の浄霊作法を厳格に保持・実践するとされる。入信は「おひかり」の授与をもって行われる。
- **秀明自然農法**: 肥料（有機・化学問わず）を一切使わず、土の本来の力を発揮させる農法を推進。
- **美の創出**: MIHO MUSEUMに代表される世界最高水準の美術工芸品の収集・公開。
- **聖典**: 『聖教書』は岡田茂吉の論文調の教えから100篇を選抜して作られた神慈秀明会の聖典（初版は昭和48年9月23日）。

### 5-1. 事件・社会的批判

- **税務問題**: 2006年、大阪国税局の税務調査により、教団が信者からの献金など約55億円を簿外資産として蓄えていたことが発覚したと報じられた。また会主一族の親族らが総額約16億円の申告漏れを指摘された（Wikipedia「神慈秀明会」）。
- **献金をめぐる訴訟**: 借金をして献金を行った元信者が教団を相手取った訴訟で、教団側に賠償を命じる判決が出されている。
- **医療否定と健康被害**: 医療行為を否定し浄霊を優先させる指導により、適切な治療機会を逸した信者が健康被害を受けたり死亡に至ったりする事例が指摘され、国会でも質問主意書が提出された。
- なおWikipedia「神慈秀明会」は批判的記述の比重が大きい記事であり、上記の各点は同記事の記述に基づくものとして帰属を明示する。

## 6. 宗教学的・歴史社会学的意義

世界救世教の分派の中で最大規模に成長した事例であり、創始者（会主）のカリスマが教祖の教義以上に教団形成へ影響した事例として論じられる。美術館（MIHO MUSEUM）を通じた文化事業と宗教活動の連携でも著名である。
