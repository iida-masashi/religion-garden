# 神慈秀明会 専門構造分析ノート

> [!summary] 要旨
> 神慈秀明会（じんじしゅうめいかい）は、世界救世教の有力教会「秀明教会」を率いていた[[小山美秀子]]（1910-2003）が1970年（昭和45年）に独立・創立した単立宗教法人である。滋賀県甲賀市信楽町に聖地「神苑」と「MIHO MUSEUM」を構え、岡田茂吉の教えに基づく浄霊、秀明自然農法、美の創出を実践している。

## 3. 創始者と沿革

小山美秀子は1941年に岡田茂吉に入信し、世界救世教最大規模の「秀明教会」を築き上げた。岡田茂吉の死後、教団運営・教理解釈をめぐり教団本部と意見を異にし、1970年3月に教団を離脱・独立した。

滋賀県信楽の山中に広大な聖地「神苑」を造成し、世界的建築家I.M.ペイ設計による神殿・鐘塔、および「MIHO MUSEUM」を開館させた。

## 4. 歴史変遷クロノロジー

```
・1941年: 小山美秀子、岡田茂吉に入信
・1952年: 秀明教会設立
・1970年: 世界救世教から独立、「神慈秀明会」立教
・1989年: 信楽神苑に神殿落成
・1997年: MIHO MUSEUM開館
・2003年: 会主・小山美秀子死去
```

---

## 5. 教理・儀礼の特色

- **純粋な浄霊の継承**: 岡田茂吉直伝の浄霊作法を厳格に保持・実践。
- **秀明自然農法**: 肥料（有機・化学問わず）を一切使わず、土の本来の力を発揮させる農法を推進。
- **美の創出**: MIHO MUSEUMに代表される世界最高水準の美術工芸品の収集・公開。
