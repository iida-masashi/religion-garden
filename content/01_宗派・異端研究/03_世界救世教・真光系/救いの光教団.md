# 救いの光教団 専門構造分析ノート

> [!summary] 要旨
> **救いの光教団**（すくいのひかりきょうだん）は、旧世界救世教の有力大教会であった「神成教会」の会長・**大沼光彦**が、教団中央の一元化政策に伴い1972年（昭和47年）に世界救世教から分離独立して創立した単立宗教法人である。教団本部は神奈川県横浜市鶴見区に所在し、静岡県熱海市上多賀に聖地「**至福郷**」を造営して活動している（外部資料で熱海市を本部と混同する例が多いが、登記上の本部は横浜市である）。岡田茂吉直伝の浄霊法と御神書の実践を重んじている。

## 3. 創始者と沿革

### 創始者・大沼光彦と神成教会
創始者の大沼光彦は、岡田茂吉存命期より布教に励み、神奈川・横浜を中心に一大勢力を誇った「神成教会」の教会長を務めた。神成教会は世界救世教の初期発展を支えた大教会の一つであった。

### 1972年の一元化離脱と教団設立
1960年代末から始まった世界救世教の一元化政策（各大教会の資産・人事・指揮権の中央集権化）に対し、大沼は教会の自立性と信徒の信仰環境を守るため一元化に反対した。
1972年（昭和47年）、大沼光彦は神成教会の信徒とともに世界救世教を離脱し、「**救いの光教団**」を設立して単立宗教法人としての認証を得た。

### 聖地「至福郷」の造営
教団本部は布教基盤である横浜市鶴見区に置く一方、明主様ゆかりの地である静岡県熱海市の上多賀地区に独自の聖地「**至福郷**」を造成。神殿や礼拝施設を整備し、定期的な祭典・信徒修練の場として活用している。

### 歴代代表者
- **初代**: 大沼光彦（1972年〜1987年）
- **2代**: 大沼美智子（1987年〜2007年）
- **3代**: 大沼光良（2008年〜現在）

## 4. 歴史変遷クロノロジー

```
・1972年（昭和47年）: 大沼光彦率いる神成教会が一元化を機に独立、「救いの光教団」を設立登記。
・1980年代: 静岡県熱海市上多賀に聖地「至福郷」を整備。
・1987年（昭和62年）: 初代・大沼光彦帰幽。大沼美智子が2代代表に就任。
・2008年（平成20年）: 大沼光良が3代代表に就任。
```

## 5. 教理・儀礼の特色

- **浄霊の原点遵守**: 岡田茂吉の直言に基づく手かざし（浄霊）を中心儀礼として継承している。
- **神乃光**: 機関紙「神乃光」を定期発行し、信徒への教理指導と教団動向の伝達を行っている。
