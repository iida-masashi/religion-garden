# 世界メシア教 専門構造分析ノート

> [!summary] 要旨
> 世界メシア教（旧称：主之光教団、登記旧商号：世界救世教主之光教団）は、世界救世教の開祖・岡田茂吉の直系血脈である第4代教主・岡田陽一を推戴する教団である。2010年代後半からの包括宗教法人世界救世教との教理・人事・法人関係をめぐる対立を経て、2018年1月30日に包括関係を解除され、2020年2月4日に「世界メシア教」への改称・独立色を強めた。2024年12月24日、世界救世教との間で和解が成立した。

## 3. 創始者と天啓・社伝

岡田茂吉が晩年に提唱していた「メシア降臨」の教理を重視。包括宗教法人世界救世教内部の対立から離脱し、第4代教主・岡田陽一のもとで「世界メシア教」として再編された。教団側は、岡田茂吉が1950年に団体名を世界救世（メシア）教に改称しキリスト教と呼応する救済を宣言したことに基づくと説明する（教団側の主張として分離する）。

## 4. 沿革・歴史変遷

```
・1935年: 岡田茂吉、開教
・1980年代: 教団内の管長地位確認訴訟等を経て、主之光教団はいづのめ教団・東方之光と並ぶ被包括法人の一つとして成立（成立時期の詳細は§12）
・2017年: 四代教主・岡田陽一の行動を東方之光側が尾行・盗聴・盗撮したとされ、教主のキリスト教信徒との接触をめぐり内紛が表面化
・2018年1月30日: 世界救世教責任役員会の採決により、主之光教団に対する包括・被包括関係が廃止された
・2018年6月: 岡田陽一の教主推戴が取り消される
・2020年2月4日: 「世界メシア教」へ改称（団体名の復活）
・2024年12月24日: 東京高裁で世界救世教と和解成立（解決金13億円の支払い、分与物件の返還不要、熱海本部5階・教主公邸の明け渡し等）
・2025年6月5日: 法人登記上の商号を「世界救世教主之光教団」から「世界メシア教」へ変更
・2025年10月1日: 法人本店を熱海市田原本町9番1号熱海第一ビル4階へ移転
```

## 5. 教理・儀礼・神観の深層解剖

- **メシア教への回帰**: 岡田茂吉が1950年代に構想した「世界メシア教」の原点への回帰を標榜。
- **神の子としての自覚**: 浄霊実践とともに、各信徒が神の子供・メシアとして新しく生まれる信仰を説く。
- **活動の柱**: 「キリスト教の完成版」というスローガンのもと、祈りによる心の救い、和ヴィーガン食（和菜食）の推進、音楽活動による人心の癒しという「祈り、食、音楽」を活動の柱とする（Wikipedia「世界メシア教」）。

### 5-1. 事件・不祥事

- **教団内紛と法廷闘争**:
  包括法人世界救世教および他の被包括教団との間で、教主の地位や教団財産・商標権を巡る激しい対立・訴訟が発生した。主之光教団側は包括管長地位確認・包括関係解消の無効を求めて静岡地裁沼津支部に提訴し、仮処分は認められず、本訴は第一審で棄却、東京高裁への控訴後に裁判所から和解が提案され、2024年12月24日に和解が成立した（Wikipedia「世界メシア教」「世界救世教」）。
- **商標**: 主之光教団は2018年10月に文字商標「世界メシア教」を特許庁に登録。世界救世教は2度にわたり反対意見を提出したが、特許庁は2019年12月に商標登録を認めた。

## 6. 宗教学的・歴史社会学的意義

世界救世教の二次分裂の中核事例であり、「教主の血脈継承とカリスマ」対「法人執行部による統治」という新宗教内部統治の対立軸を示す。キリスト教との習合を前面化した教理転換（メシアとしての新生）は、岡田茂吉の救世主思想の再解釈として位置づけられる。
