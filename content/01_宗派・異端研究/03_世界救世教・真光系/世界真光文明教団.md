# 世界真光文明教団 専門構造分析ノート

> [!summary] 要旨
> 世界真光文明教団（せかいまひかりぶんめいきょうだん）は、世界救世教の元幹部であった[[岡田光玉]]（1901-1974）が1959年（昭和34年）に創始した新宗教である。手のひらから放射される霊光により心身を浄化する「真光の業（手かざし）」を中核とする。1974年の光玉死去に伴い、関口榮が継承した「世界真光文明教団（中伊豆）」と、光玉の養女・岡田恵珠が率いた「崇教真光（高山）」とに教団が二分された。

## 3. 創始者と沿革

岡田光玉（陸軍将校を経て世界救世教小田原支部で活動）は、1959年2月27日朝、「立て、立つべし、名は光玉と名乗れ」との神示（天啓）を受け、同年「L・H陽光子友乃会」を設立。1963年に「世界真光文明教団」として宗教法人認証を得た。

1974年の光玉死去後、後継者を巡って関口榮（教団責任役員）と岡田恵珠（光玉の養女）の間で裁判闘争が勃発。和解の結果、宗教法人格および伊豆の主座本宮は関口榮側が引き継ぎ「世界真光文明教団」として存続した。

## 4. 歴史変遷クロノロジー

```
・1959年: 岡田光玉、神示を受け立教（L・H陽光子友乃会設立）
・1963年: 宗教法人「世界真光文明教団」設立登記
・1974年: 初代教え主・岡田光玉死去。後継者紛争が発生
・1982年: 東京高裁にて和解成立（関口榮が教団代表として確定）
・1987年: 中伊豆に「主座本宮」神殿を建立
```

## 5. 教理・儀礼の特色

- **真光の業（手かざし）**: 手のひらから放射されるス神の霊光により、憑依霊の除霊や肉体の毒素浄化を行う。
- **火の洗礼**: 水の時代から火の時代への大転換に伴い、人類が霊的に浄化・選別されるとする終末論的教義。

---

## 5-1. 事件・不祥事

- **1970年代 真光後継者紛争・法廷闘争**:
  岡田光玉死去に伴う後継指名（関口榮か岡田恵珠か）をめぐり、全国の道場・信徒を巻き込む激しい対立と訴訟が展開され、教団が「世界真光文明教団」と「崇教真光」に完全に分裂した。
