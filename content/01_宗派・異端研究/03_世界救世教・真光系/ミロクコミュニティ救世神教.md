# ミロクコミュニティ救世神教 専門構造分析ノート

> [!summary] 要旨
> ミロクコミュニティ救世神教（旧称：救世神教）は、世界救世教の幹部であった[[谷元後藤英男]]が1970年（昭和45年）に独立・創立した教団である。三重県津市安濃町の聖地「神恩郷」には建築家・黒川紀章設計による神殿・施設群が立ち並び、自然農法やEM技術を活用した循環型コミュニティづくりを推進している。

## 3. 創始者と沿革

後藤英男は世界救世教で熱心に布教活動を行っていたが、1970年に岡田茂吉の神霊の啓示を受け「救世神教」として独立。三重県津市の山林を開発して「神恩郷」を造成した。2018年に「ミロクコミュニティ救世神教」へと改称した。

---

## 4. 歴史変遷クロノロジー

```
・1970年: 救世神教立教（三重県）
・1980年代: 聖地「神恩郷」建設推進（黒川紀章設計）
・2018年: 「ミロクコミュニティ救世神教」へ改称
```

## 5. 教理・儀礼の特色

- **五六七（ミロク）の世の建設**: 浄霊による霊体浄化と、自然農法・環境保全技術（EM等）を組み合わせた理想共同体の実現。
