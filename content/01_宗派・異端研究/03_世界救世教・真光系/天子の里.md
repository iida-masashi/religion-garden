# 天子の里 専門構造分析ノート

> [!summary] 要旨
> 天子の里（てんしのさと）は、1981年（昭和56年）に矢井清勝によって創始された新宗教団体（当初の名称は「神鏡の里」、1986年に改称）。本部は岐阜県岐阜市。創始者の矢井清勝は元[[世界救世教]]信者・幹部であったが、教団内での信仰上の対立から1973年に除名処分を受けた後、自身を「神の分身」と位置づける独自の教団を設立したとされる。本ノートの内容は単一のブログ記事（新宗教研究ブログ、2012年）のみに依拠しており、個別的事実は未検証の要素を多く含む（留保参照）。

## 3. 創始者と天啓・社伝

### 矢井清勝の歩みと世界救世教入信
創始者の矢井清勝は1925年（大正14年）2月、岐阜県に生まれる。明治大学商学部を卒業後、軍隊に入隊。終戦後は繊維事業に着手したものの失敗。銀行員として勤務するかたわら、1952年（昭和27年）に岡田茂吉の率いる[[世界救世教]]に入信・布教活動に挺身した（以上、ブログ記事に基づく）。

### 救世教除名と職業の変遷
世界救世教内部での信仰上・教義上の対立により、1973年（昭和48年）に教団から除名処分を受ける。除名後は養蜂業、プロパンガス販売会社、駐車場の管理運営など職を転々とした（ブログ記事に基づく）。

---

## 4. 沿革・歴史変遷

1981年（昭和56年）12月、岐阜市において「神鏡の里」を立教。1986年（昭和61年）に教団名を「天子の里」へと変更した。

```
・1925年 (大正14年): 矢井清勝、岐阜県に生まれる。
・1952年 (昭和27年): 世界救世教に入信。
・1973年 (昭和48年): 信仰対立により世界救世教を除名される。
・1981年 (昭和56年): 岐阜市にて「神鏡の里」を立教。
・1986年 (昭和61年): 教団名を「天子の里」に改称。
```

## 5. 教理・儀礼・神観の深層解剖

### 1. 「生神・神の分身」説
創始者である矢井清勝自身が「神の分身」であり、最高神の意志が地上（現世）において肉体をもって生きていると説く。世界救世教における岡田茂吉（明主様）の神格化構造を、創始者自身に直接置換した教理的帰結が見られる（ブログ記事の記述に基づく解釈）。

### 2. 芸能関係者・人物エピソード（未検証）
ブログ記事は、矢井清勝が女優・タレントの**岡田奈々**の実父であると記す。しかし本照合では他の資料による裏付けは一切得られなかったため、この親子関係の主張は**未検証**として分離する。
