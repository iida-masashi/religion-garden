# 世界救世教黎明教会 専門構造分析ノート

> [!summary] 要旨
> **世界救世教黎明教会**（せかいきゅうせいきょうれいめいきょうかい）は、旧世界救世教の有力教会「黎明教会」の会長であった**多田光行**が、1970年（昭和45年）の教団一元化問題に伴い世界救世教から分離独立して設立した単立宗教法人である。教団名に「世界救世教」を冠しているが包括宗教法人・世界救世教とは法的に全く別の独立教団である。京都府京都市山科区を本拠とし、「黎明教会資料研修館」を擁する。なお、本教団の東京支部が1971年に単立独立したものが[[東京黎明教会]]である。

## 3. 創始者と沿革

### 創始者・多田光行と黎明教会
多田光行は岡田茂吉の直弟子として黎明教会の教会長を務め、関西圏において有力な信徒基盤を形成した。岡田茂吉に対する篤い純粋信仰で知られ、明主様の御教え・御神書の原典保存と実践を重んじた。

### 1970年の一元化離脱
1960年代末から1970年代初頭にかけて世界救世教本部が進めた「包括一元化」（全国教会の財産・人事・管理の中央統合）に対し、信徒教育と原点教理の自立性を守る見地から異議を唱え、1970年（昭和45年）に包括関係を離脱して単立の「世界救世教黎明教会」として独立した。

### 東京支部の独立（東京黎明教会）
黎明教会に合流していた神成教会の旧牛込柳町支部長・長島すゞ子は、1971年に「世界救世教黎明教会 東京支部」として活動を開始したが、その後東京都中野区を本拠として独自の単立宗教法人「[[東京黎明教会]]」として発展・分離した。

### 歴代代表者
- **初代**: 多田光行（1970年〜1985年）
- **2代**: 多田歌恵（1986年〜現在）

## 4. 歴史変遷クロノロジー

```
・1970年（昭和45年）: 多田光行会長率いる黎明教会が一元化を拒否し世界救世教から分離独立。
・1971年（昭和46年）: 東京支部が発足（のちの東京黎明教会へ）。
・1985年（昭和60年）: 初代・多田光行会長帰幽。
・1986年（昭和61年）: 多田歌恵が2代代表に就任。『多田光行会長先生 追想』（洛東社）刊行。
・1989年〜1992年: 洛東社より『多田光行集』全4巻を順次刊行。
```

## 5. 教理・儀礼の特色

- **純粋信仰と教理継承**: 岡田茂吉の生前の御神書・論文集の原典的継承を重視し、独自の教学書として『多田光行集』（第1巻〜第4巻）などを編纂している。
- **資料研修館**: 京都市山科区に「黎明教会資料研修館」を設置し、初期の教団史料や岡田茂吉関係の一次資料を保存・研修の場としている。
