# 念法眞教 専門構造分析ノート

> [!summary] 要旨
> 念法眞教（ねんぽうしんきょう）は、小倉霊現（初代燈主、-1982）が1925年（大正14年）8月3日に立教した仏教系新宗教教団である。阿弥陀如来からの託宣（教団は「ご霊告」と表現する）を立教の起源とし、大阪市鶴見区の総本山金剛寺を本拠とする。教典は『念法法語集』（旧稿の『念法教典』は実在を確認できない幽霊書名）。当代燈主は第4代・桶屋良祐（2018年就任）であり、旧稿の「現燈主：小倉良造」は実在しない人名だった。信者数は426,190人（文化庁『宗教年鑑』令和7年版。令和6年版では約38.7万人）。旧稿の法人番号6120005005886は国税庁に存在しない誤番号であり、再検証（2026-11-16）で正しい法人番号5120005002157を特定した。

## 3. 創始者と天啓・社伝

小倉霊現は大峰山で修験道の修行をした後、1925年（大正14年）8月3日に阿弥陀如来から託宣を受けた。教団はこの託宣を「ご霊告」と表現し、同日を立教とする。1928年（昭和3年）に「神仏心霊感応会」を発会して四天王寺前に道場を設立し、1931年（昭和6年）に機関紙『鶯乃聲』を創刊した。1982年（昭和57年）に死去した。

旧稿が記した創始者の生年「1886年」は、今回照合したWikipedia本文では確認できなかったため未検証とする（§12参照）。

| 代 | 燈主 | 就任 | 退任 |
| :--- | :--- | :--- | :--- |
| 初代 | 小倉霊現 | 1925年 | 1982年 |

| 3代 | 稲山霊芳（生前に後継指名） | 2001年 | 2018年 |
| 4代 | 桶屋良祐 | 2018年 | 現在 |

## 4. 沿革・歴史変遷

```
・1925年8月3日: 小倉霊現、阿弥陀如来の託宣（ご霊告）を受け立教
・1928年: 「神仏心霊感応会」を発会、四天王寺前に道場を設立
・1931年: 機関紙『鶯乃聲』を創刊
・1939年: 天台宗傘下に入り『金剛教会』に改称
・1947年: 『小倉山金剛寺』の名で独立
・1952年: 現教団名『念法眞教』に改め、宗教法人格を取得
・1971年: 民放ラジオの布教番組『心のいこい』放送開始
・1973年: 全日本仏教会に加盟
・1982年: 初代・小倉霊現没。次男の由貴夫（良現）が二代燈主に就任し小倉霊現を襲名
・2001年: 二代目小倉霊現没。稲山霊芳が三代燈主に就任
・2017年3月5日: 桶屋良祐教務総長を四代燈主に任命すると発表（4月1日付で三代燈主代行者）
・2018年6月17日: 三代燈主・稲山霊芳が死去し、桶屋良祐が四代燈主に就任
```

## 5. 教理・儀礼・神観の深層解剖

- **本尊**: 阿弥陀如来。立教の起源は阿弥陀如来の託宣（ご霊告）とされる。
- **教典**: 『念法法語集』。ラジオ布教番組『心のいこい』（1971年開始）ではこの教典の内容が紹介・布教されてきた。
- **機関紙・月刊誌**: 機関紙『念法時報』の巻頭には「教団を愛するとは、人を愛し、国を愛することである」等の「聖語」が掲げられる。月刊誌『鶯乃声』には保守論客・産経知識人の投稿・転載が多いとされる。
- **お練り**: 各地の念法寺・教会と独特の「お練り」行列で知られる。
- 旧稿が掲げた「五箇条の御教え」（親孝行、感謝等）の具体的内容および「現世浄土建設」という表現は、今回照合した資料では確認できなかった（§12参照）。

## 6. 宗教学的・歴史社会学的意義

念法眞教は、愛郷心に立脚しながら国土防衛と反共を強く説く保守的な政治姿勢を特徴とする新宗教として記述される。機関紙に教育勅語の原文と口語訳を連載するなど、初代からの路線が継承されてきたとされる。戦時下には新体制運動・翼賛思想を鼓舞して教勢を拡大したという記述があるが、Wikipedia上では当該箇所に「要出典」が付されており、評価は留保する。
