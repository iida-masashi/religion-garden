# フリーメイソン用語集

> [!summary] 要旨
> 本ノートは、Vault 内のフリーメイソン関連ノート群（[[フリーメイソン]]、[[天空ロッジ]]、[[ソレイユ・ルヴァン]]、[[フリーメイソンの乾杯と符丁]]）に登場する主要用語を、カテゴリ別の表で整理した補助資料である。定義は関連ノート本体と、その典拠である公刊資料（Duncan『Duncan's Masonic Ritual and Monitor』1866年、Morgan『Illustrations of Masonry』1827年、いずれもパブリックドメイン）および各公式資料に基づく。出典で確認できない定義・語源は記載せず、未検証の事項は §11 に集約した。儀式の具体的手順そのものではなく、用語の意味と位置づけを扱う。

**出典の略号**（各表の「出典・関連」欄で使用）:

- = [[フリーメイソン]]（節番号を併記）
- = src_freemasonry_duncan_1866_ja（Duncan 1866年 全訳）
- = Duncan 所収の Oliver『象徴的メイソンリー辞典』抜粋（同上ファイル内）
- = src_freemasonry_morgan_1827_ja（Morgan 1827年 全訳）
- = [[天空ロッジ]]

**凡例**: 管轄（グランドロッジ）によって用語法・制度には差異がある。本表は特記なき限り英米系（正規系）の一般形に基づき、管轄差が大きいものは定義中に注記した。符丁（ジャーゴン）類は簡潔な定義にとどめ、詳細は [[フリーメイソンの乾杯と符丁]] を参照されたい。

## 4. 儀礼・所作

| 用語 | 読み | 英語 | 定義 | 出典・関連 |
|:--- |:--- |:--- |:--- |:--- |
| 認証方法 | にんしょうほうほう | Modes of Recognition | 握手・合言葉・サイン等の、会員であることを互いに確認する伝統的方法。UGLE は「秘密とされるのはこの認証方法のみ」と公式に説明する | |

| ペナルサイン | ペナルサイン | Penal Sign | 義務違反への象徴的罰則を暗示するサイン。アダムの堕落とその罰をも思い起こさせるものと説かれる | |
| グリップ | グリップ | Grip | 学位ごとに異なる握手。認証方法の一つ。詳細は [[フリーメイソンの乾杯と符丁]] も参照 | |

| トークン | トークン | Token | 認証のための証し。グリップ等を指す。本質的な秘密はサイン・グリップ・通行の言葉・トークンからなると説かれる | |

| 代わりの言葉 | かわりのことば | Substitute Word | 失われた真のマスターの言葉に代えて採用された言葉。五つの同胞の要点の上で低い声で授けられる。Duncan 所収の辞典抜粋はその語形（MAH-HAH-BONE）を記す | |
| 義務（誓約） | ぎむ（せいやく） | Obligation | 祭壇前で聖典の上に手を置き、各学位の秘密を守ること等を誓う誓約。入会儀式の中核 | |

| フードウィンク | フードウィンク | Hoodwink | 候補者に施される目隠し。暗闇が無知を、光の回復が知識を象徴すると説かれる | |
| アラーム | アラーム | Alarm | ロッジのドアへのノック。学位ごとに回数が定められ、内部との問答を経て入室が許される | |

| 講義 | こうぎ | Lecture | 各学位に付随する問答形式の教育部分。儀式・伝承・道徳的教えを説明する | |

## 11. 留保（中立的併記・未確定要素）

> [!warning] 留保事項
> - **語源の扱い**: 本表では、出典で確認できない語源説は記載しない方針を取った。"Entered"（徒弟）の名簿記入説については、公式教育資料（Grand Lodge of Georgia『The Lodge System of Masonic Education』1961年）に明記されることが本体の第2ラウンド再調査で確認された一方、Stevenson『The Origins of Freemasonry』（1988年）は名簿記入（booked）とロッジ入会（entered）を別段階として区別しており、両論併記とする（本体 §3・§12）。学位名・用語の語源説には諸説あるものが多く、確定情報がある場合に限って追記する。
> - **コーワンの語源（解消）**: Mackey『Encyclopedia』により、初出は Schaw Statutes（1598年）であり、Jamieson『スコットランド語辞典』の3義が引かれることを確認した（§4「コーワン」に反映）。語の究極の由来については Mackey 自身も諸説（古スウェーデン語・フランス語等）を併記しており、その一点確定はしていない。
> - **NMJ の学位名（解消）**: スコティッシュ・ライト北部管轄（NMJ）の第24級の現行名は "Brother of Tolerance" と確定した（NMJ 公式、本体 §12）。§2 に収録した。なお NMJ は学位名をたびたび改訂しているため、本表のスコティッシュ・ライト学位は南部管轄（SJ）の名称を基本とし、NMJ の学位名は収録を代表例に留める方針は維持する。
> - **数値の時点依存性**: 日本グランドロッジの規模（公式サイトの18ロッジ・会員数は約1,400人と約1,500人が公式内で併存）は他資料の数値と差異があり（本体 §12）、時点依存の参考値として扱う。Soleil Levant の会員数（約30名）も同様に時点依存である。
> - **符丁の収録（解消）**: 「∴」（三つの点）と「2B1ASK1」は、[[フリーメイソンの乾杯と符丁]] の調査で出典付きで確認できたため、本表に収録した（§5・§4）。
> - **第2階級の救済権（解消）**: 「権利としての」救済請求権はマスターメイソンのもので、Fellow Craft にはないことが本体 §12 の再調査で確定した（Mackey 1856年、フィリピン・グランドロッジ憲章）。§4「救済」の定義に反映した。
> - **管轄差の一般性**: 本表は英米系の一般形を基本とするが、役職の選出方法・宝飾・継承順等には管轄差が大きい（本体 §5-1）。個別管轄の現行憲章による確認は行っていない。
