# クリシュナ意識国際協会（ISKCON） 専門構造分析ノート

> [!summary] 要旨
> クリシュナ意識国際協会（ISKCON）は、1966年にA.C.バクティヴェーダーンタ・スワミー・プラブパーダがニューヨークで創設した、ガウディーヤ・ヴァイシュナヴァ派（チャイタニヤ派）の国際的伝道組織である。最高神クリシュナへのバクティ（献身）を中心とし、マハー・マントラの唱名（ジャパ）、菜食主義、四つの規制原則（肉食・酒類等・ギャンブル・婚外性行為の禁止）を特徴とする。日本では1969年後半から活動が始まり、1970年にプラブパーダが来日した。現在の日本の中心拠点は東京都江戸川区船堀の ISKCON New Gaya Japan（船堀寺院）であり、併設の菜食レストラン「ゴヴィンダス」を運営している。

## 1. 命題の構造（伝統的解釈 vs 運動の独自性）

| 比較考察軸 | 伝統的なヒンドゥー教解釈 | ISKCONの独自解釈・実践 |
| :--- | :--- | :--- |
| **『バガヴァッド・ギーター』の位置** | 多様な解釈伝統が併存し、シヴァ派・シャクティ派等ではクリシュナをヴィシュヌの化身（アヴァターラ）と見る | クリシュナ自身を最高人格神（スヴァヤム・バガヴァーン）とし、「あるがままの詩（As It Is）」としてプラブパーダ訳注を唯一の権威とする |
| **救済の手段** | ヴァルナに基づく義務（ダルマ）の遂行、ヨーガ、知識等、多様な道 | 現代（カリ・ユガ）ではクリシュナの御名の唱名（ハレ・クリシュナ・マントラ）が唯一の実効的手段 |
| **出家と世俗** | 出家者（サンニャーシー）と在家者の役割分担 | 在家信者も寺院コミュニティに参加し、四規制原則を守る「寺院生活」モデルを西洋社会に移植 |
| **布教** | 原則として生得的帰属が中心で、改宗勧誘は稀 | 積極的な街頭唱名（ハリナーマ）、書籍配布、レストラン経営を通じた布教を組織化 |

## 3. 創始者と天啓・社伝

プラブパーダは師であるバクティシッダーンタ・サラスヴァティーから「英語でクリシュナ意識を西洋に広める」よう指示を受けたとされ、69歳で渡米した。師弟継承（グル・パンパラー）はブラフマー・マーダヴァ・ガウディーヤ系譜に連なるとされる。

## 4. 沿革・歴史変遷

- 1966年：プラブパーダがニューヨークでISKCONを設立
- 1970年：ビートルズのジョージ・ハリスンが「マイ・スウィート・ロード」を発表し、ハレ・クリシュナ・マントラが世界的に知られる
- 1977年：プラブパーダがヴリンダーヴァンで死去

### 日本での展開

- 1969年後半：弟子たちが日本での活動を開始したとされる
- 1970年8月：プラブパーダが来日し、渋谷区大橋に初の拠点が置かれた（弟子スダーマ・スワミーらが布教）とされる
- 以後、拠点を移転しながら活動を継続。現在の船堀寺院は「New Gaya（新ガヤー）」と呼ばれ、ヒンドゥー教の聖地ガヤーにちなむ名称とされる
- 船堀への移転時期については情報源により差異がある（留保参照）

## 5. 教理・儀礼・神観の深層解剖

### 5-1 神観・教理

- **クリシュナ至上主義**: クリシュナを最高人格神とし、他の神々はその顕現・分身と位置づける一神教的構造を持つ
- **バクティ（献身）**: クリシュナへの愛情ある献身的奉仕（バクティ・ヨーガ）が解脱の道とされる
- **マハー・マントラ**: 「ハレー・クリシュナ、ハレー・クリシュナ、クリシュナ・クリシュナ、ハレー・ハレー／ハレー・ラーマ、ハレー・ラーマ、ラーマ・ラーマ、ハレー・ハレー」の唱名が中心実践。入門弟子はジャパマーラーで毎日16周（1周108回）の唱名が義務とされる
- **四つの規制原則**: 肉食禁止（菜食主義）、酒・薬物類の禁止、ギャンブル禁止、婚外性行為禁止
- **プラサーダム**: クリシュナに捧げた供物（菜食料理）を信者が食す実践。レストラン「ゴヴィンダス」はこの実践の対外的展開

### 5-2 主要経典

- 『バガヴァッド・ギーター あるがままの詩』（プラブパーダ訳注）
- 『シュリーマド・バーガヴァタム』（プラブパーダ訳注）
- 『チャイタニヤ・チャリターリタ』

## 6. 宗教学的・歴史社会学的意義

ISKCONは、インドのバクティ伝統を西洋のカウンターカルチャー層に移植し、さらに世界へ再輸出した「逆輸入型」の新宗教運動として研究対象となってきた。日本においては信者規模は小さいものの、船堀寺院併設の菜食レストラン「ゴヴィンダス」が「宗教と食」の交点として飲食関連ノート群と接続する点が特徴である。運営は MSG Japan Corporation が担うと公式センター一覧に記載されており、宗教活動と事業活動の併存形態として注目される。
