# 太道教 専門構造分析ノート

> [!summary] 要旨
> 太道教（たいどうきょう）は、天理教の支教会長を務めていた中村しげ（大慈）が昭和13-15年（1938-1940年）頃に独立・創立した教団である。東京都杉並区阿佐谷南1-1-38に本部神修殿を構え、境内に「阿佐ヶ谷猿田彦神社」を併設する二重空間構造を持つ。天理教からの独立後、霧島講の講元を経て太道教を立教し、戦後に椿大神社から猿田彦大神を勧請したとされる。

## 3. 創始者と沿革

中村しげ（大慈）は、病気を契機に天理教へ入信し、宣教所から支教会へと昇格させる実績を残したが、後に天理教を離脱。言霊学者の武智時三郎とともに「皇学林塾」を創立した。

昭和13年（1938年）、「信仰を改めよ」との神示を受けて霧島神宮宮司と面会し、関東における霧島講の講元許諾を得たとされる。昭和15年（1940年）に「太道教」として届け出を行い、東京・阿佐ヶ谷の地に本部神修殿を建立。第二次世界大戦後、三重県の椿大神社より御分霊を勧請して「阿佐ヶ谷猿田彦神社（杉並猿田彦神社）」を境内に創建・併設した。

Wikipedia日本語版「天理教」記事の分派一覧においても「太道教（1940年、東京都杉並区）中村しげの神がかりにより太道教々檀として独立」として記録されている。

## 4. 歴史変遷クロノロジー

```
・昭和初期: 中村しげ、天理教に入信し支教会長を務める
・1938年（昭和13年）: 天理教離脱後、神示を受け霧島講の講元となる
・1940年（昭和15年）: 「太道教」を設立・届出。阿佐ヶ谷に神修殿建立
・戦後: 椿大神社より猿田彦大神を勧請、「阿佐ヶ谷猿田彦神社」を境内併設
・現代: 地域神社（猿田彦神社）と太道教本部神修殿の二重体制で護持
```

## 5. 教理・儀礼の特色

- **神社併設型二重空間構造**: 一般参拝者向けには地域神社「阿佐ヶ谷猿田彦神社」として開かれつつ、内部に太道教本部「神修殿」を配置する空間管理構造。
- **神道祭祀と天理教的背景の混交**: 創始者の出自は天理教にあるが、教理・奉斎神は霧島神宮（瓊瓊杵尊）および椿大神社（猿田彦大神）の教派神道・復古神道系譜へ移行している。
