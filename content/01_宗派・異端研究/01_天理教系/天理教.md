# 天理教 専門構造分析ノート

> [!summary] 要旨
> 天理教（てんりきょう）は、1838年（天保9年）に中山みきが「月日のやしろ」となったことを起点とする、日本を代表する大型新宗教。奈良県天理市三島町に教会本部（おぢば）を置く。信仰の根本対象は親神「天理王命（てんりおうのみこと）」と、人類創造の地点とされる「ぢば（かんろだい）」。明治期の国家神道体制下での激しい弾圧を耐え抜き、1908年（明治41年）に一派独立。戦後、政府に強制された教義改変を廃して「原点復元」を完了した。天理大学、天理図書館、天理よろづ相談所病院などの巨大な教育・文化・医療インフラを擁し、独自の宗教都市を形成している。

## 3. 創始者と沿革

天保9年（1838年）10月26日、大和国山辺郡庄屋の妻・中山みきに親神が憑依し「月日のやしろ」となった。「貧に落ちきれ」の教えのもと家財を施し、貧民救済・病気平癒の祈り（おさづけ）を実践した。警察や旧来宗教からの迫害・投獄（18回の拘留・検挙）を受けつつ教義を体系化し、『おふでさき』『みかぐらうた』等の原典を遺した。

1896年（明治29年）の内務省訓令（秘密訓令第12号）をはじめとする厳しい国家統制を避けるため、神道本局の傘下に入り教義の妥協（神道風教典の導入）を余儀なくされたが、1908年に「天理教」として一派独立を達成した。

戦時下の「革正」による教義改変を経て、1945年の終戦とともに国家神道様式を全面廃止。教祖生前の直筆・教えに基づく「原典復元」を断行し、本来の「陽気ぐらし」を目指す教義へ回帰した。

## 4. 歴史変遷クロノロジー

```
・1838年（天保09年）: 中山みきに親神が憑依、「立教の元日」とされる
・1882年（明治15年）: 警察により石造甘露台の礎石が没収される
・1887年（明治20年）: 教祖・中山みきが現身を隠す（享年90歳）
・1896年（明治29年）: 内務省訓令甲第12号（秘密訓令）による取り締まり
・1908年（明治41年）: 神道本局より離脱し、「天理教」として一派独立認可
・1925年（大正14年）: 天理外国語学校（現・天理大学）創立
・1945年（昭和20年）: 終戦に伴い「原典復元」を宣言、国家神道様式を廃止
・1954年（昭和29年）: 自治体「天理市」誕生
・1966年（昭和41年）: 公益財団法人天理よろづ相談所病院「憩の家」開設
```

## 5. 教理・儀礼の特色

- **陽気ぐらしとたすけ一条**: 人類全員が親神の子として互いに助け合い、心豊かに生きる「陽気ぐらし」を理想世界とする。
- **八つのほこり**: 人間の悪しき心遣い（おしい、ほしい、にくい、かわい、うらみ、はらだち、よく、こうまん）を「ほこり」に例え、日々掃除するように心を澄ます。
- **かぐらづとめとおさづけ**: 親里おぢばの甘露台を取り囲んで勤める「かぐら・ておどり」を中心儀礼とし、信者は病気平癒を祈る「おさづけ」を取り次ぐ。
