# 生長の家 専門構造分析ノート

> [!summary] 要旨
> 生長の家（せいちょうのいえ）は、1930年（昭和5年）に谷口雅春によって雑誌『生長の家』の創刊（誌上立教）とともに創始された新宗教。大本の霊学や西洋のニューソート思想を統合し、「人間・神の子」「唯心実相（病気や悪は本来存在しない）」を説く。戦後は皇室中心主義・保守政治運動（元号法制化運動、日本会議の前身「日本を守る会」結成）を牽引したが、第3代総裁・谷口雅宣のもとで「脱原発・環境主義・自民党支援停止」へと路線を完全転換した。これに反発する保守派信徒群（「谷口雅春先生を学ぶ会」等）との分裂構造を抱える。

## 3. 創始者と沿革

谷口雅春（1893-1985）は早稲田大学英文科を中退後、大本に入信し機関誌編集や出口王仁三郎の補佐を担当した。その後、一灯園や西洋のニューソート思想（フェニアス・クインビー、エマ・カーティス・ホプキンス等）を研究し、1929年に「人間神の子、物質・悪・病気は本来なし」との直観（天啓）を得た。

1930年3月1日、月刊誌『生長の家』を創刊（誌上立教）。主著『生命の實相』は通算数千万部を記録する大ベストセラーとなり、戦前・戦後を通じて中産階級や知識人に急速に受容された。

戦後は谷口雅春の指導のもと、保守・愛国主義運動を推進し、学生組織「生学連」の結成や元号法制化運動、「日本を守る会（現・日本会議の母体）」の設立を主導した。しかし第3代総裁・谷口雅宣は2000年代以降、環境保護・脱原発・国際協調路線へ大転換し、自民党支援の完全停止を決定。これに対し旧来の教義・保守路線維持を掲げる勢力が「谷口雅春先生を学ぶ会」などを立ち上げ、分立状態となっている。

## 4. 歴史変遷クロノロジー

```
・1930年: 谷口雅春、雑誌『生長の家』創刊（誌上立教）
・1932年: 『生命の實相』刊行開始
・1940年: 財団法人「大日本教化報国会」設立
・1952年: 宗教法人「生長の家」認証
・1974年: 「日本を守る会」結成に中心的存在として参画
・1985年: 創始者・谷口雅春死去。谷口清超が第2代総裁に就任
・2009年: 谷口清超死去。谷口雅宣が第3代総裁に就任
・2013年: 本部を東京都原宿から山梨県北杜市「森の中のオフィス」へ完全移転
・2016年: 参議院選挙で野党統一候補・脱原発派への支援を表明
```

## 5. 教理・儀礼の特色

- **唯心実相（ゆいしんじっそう）**: 神が創られた完全円満な世界のみが「実相（真の実在）」であり、病気・罪・悪・貧困などは人間の心が作り出した「仮相（現象・幻）」に過ぎないと説く。
- **神想観（しんそうかん）**: 正座して呼吸を整え、実相完全円満の姿を心に観じる独自の瞑想法。
- **万教帰一**: キリスト教、仏教、神道など世界のあらゆる宗教の本質は一つであるとする統合思想。

## 5-1. 事件・不祥事

- **保守政治運動からの大転換と信徒分裂**:
  かつて教団が主導した「生長の家政治連合（生政連）」および「日本を守る会」の活動を巡り、第3代総裁・谷口雅宣が政治活動からの撤退・脱原発宣言を行ったことで、従来の保守派信徒・幹部との間で法廷闘争や著作権争いを含む深刻な内紛・分裂が発生した。
