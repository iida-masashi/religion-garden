# 大本 専門構造分析ノート

> [!summary] 要旨
> 大本（おおもと）は、1892年（明治25年）に出口なお（1837-1918）が「艮の金神（国常立尊）」の神がかりを受けたことに始まり、娘婿の出口王仁三郎（1871-1948）によって教理体系化・全国展開された神道系新宗教である。「立替え・立直し」「型の大本」「霊主体従」を教理の中核に据え、近代日本の新宗教・霊術界に絶大な影響を与えた。二度にわたる国家的大弾圧（第一次・第二次大本事件）を経験した。

## 3. 創始者と沿革

1892年（明治25年）、京都府綾部の極貧の未亡人・出口なおに「艮の金神」が憑依し、いろは文字による自動筆記（お筆先）で神示を記録し始めた。1898年、本田親徳の霊学（鎮魂帰神法）を修めた上田喜三郎（後の出口王仁三郎）が合流。王仁三郎はなおの末娘・すみと結婚して教団の組織化を推進した。

王仁三郎の卓越した宣伝力と『霊界物語』の執筆、芸術・国際語エスペラントの導入により知識人・軍人層を含む大勢力を形成したが、終末論・社会批判が政府の警戒を招き、1921年の第一次大本事件、1935年の第二次大本事件という苛烈な国家弾圧を受けた。第二次事件では施設がダイナマイトで全破壊されたが、戦後の裁判で治安維持法違反について無罪が確定。戦後は平和運動・芸術活動を中心として復興した。

## 4. 歴史変遷クロノロジー

```
・1892年: 出口なおに神がかり、「立替え・立直し」を宣言（大本開教）
・1898年: 上田喜三郎（出口王仁三郎）が綾部を初訪問・合流
・1900年: 王仁三郎、出口すみの婿となり出口家へ入籍
・1918年: 開祖・出口なお死去。王仁三郎が教団運営を掌握
・1921年: 第一次大本事件発生（不敬罪容疑で検挙）
・1923年: エスペラント普及活動、世界紅卍字会との提携開始
・1935年: 第二次大本事件発生（治安維持法違反等で大弾圧、全施設破壊）
・1942年: 大阪控訴院判決にて治安維持法違反が無罪確定
・1946年: 「愛善苑」として再出発
・1952年: 宗教法人法に基づき「大本」として認証
```

## 5. 教理・儀礼の特色

- **立替え・立直し**: 現実世界の不正や物質文明の歪みを根底から清算し（立替え）、神意にかなう「みろくの世」を建設する（立直し）とする終末論的救済観。
- **型の大本**: 大本の中で起こる事象が、日本全体、ひいては全世界に縮図として現れるとする宇宙法則。
- **霊主体従**: 霊（心・精神）が主であり、体（物質・肉体）が従であるとする霊肉一体の宇宙観。
- **万教同根**: 世界の諸宗教は根源において同一の神から発しているとする世界宗教観。

---

## 5-1. 事件・不祥事

- **第一次・第二次大本事件**:
  国家神道体制下の戦前日本において最大の宗教弾圧事件。特に1935年の第二次大本事件では、治安維持法および不敬罪の容疑で幹部約千人が検挙され、綾部・亀岡の全神殿がダイナマイトで爆破・更地化された。1942年の大阪控訴院判決において治安維持法違反は全員無罪が言い渡された（[[src_omoto_primary]]、[[src_nagaoka_omoto_shichijunenshi]]参照）。
