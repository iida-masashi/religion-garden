# 創価学会 専門構造分析ノート

> [!summary] 要旨
> 創価学会（そうかがっかい、Soka Gakkai）は、教育者・[[牧口常三郎]]（1871-1944）と[[戸田城聖]]（1900-1958）が1930年（昭和5年）に設立した「創価教育学会」を起源とする日本最大の新宗教教団である。日蓮大聖人の仏法を基盤とし、第3代会長・名誉会長の[[池田大作]]（1928-2023）のもとで世界的組織「SGI（創価学会インタナショナル）」へと発展。政党・公明党の支持母体でもある。1991年（平成3年）に日蓮正宗総本山大石寺から破門され、独自の在家仏教教団として自立した。

## 3. 創始者と沿革

牧口常三郎が「価値論」に基づく教育改革運動として発足。戦時下、国家神道（伊勢神宮神札受敬）を拒否して牧口と戸田が治安維持法違反等で投獄され、牧口は獄死。戦後、出獄した戸田城聖が強力な折伏大行進を展開し、75万世帯の組織を構築した。

1960年に32歳で第3代会長に就任した池田大作は、公明党の結成（1964年）、創価大学の創立（1971年）、SGIの発足を推進し、世界192カ国・地域へ組織を拡大した。1990年代初頭の「宗門問題」により日蓮正宗から破門された後は、教規改正を行い単立宗教法人として確立した。

## 4. 歴史変遷クロノロジー

```
・1930年: 牧口常三郎・戸田城聖により「創価教育学会」設立
・1943年: 治安維持法違反・不敬罪で幹部検挙、牧口会長獄死（1944年）
・1951年: 戸田城聖が第2代会長に就任、「折伏大行進」開始
・1952年: 宗教法人設立認証
・1960年: 池田大作が第3代会長に就任
・1964年: 公明党を結成
・1975年: SGI（創価学会インタナショナル）発足
・1991年: 日蓮正宗（阿部日顕管長）より破門通告・独立
・2013年: 信濃町に「広宣流布大誓堂」落成
・2023年: 名誉会長・池田大作死去
```

## 5. 教理・儀礼の特色

- **南無妙法蓮華経と人間革命**: 一人ひとりが自身の境涯を仏の境地へと変革（人間革命）し、家庭・社会・世界を向上させる。
- **座談会中心主義**: 毎週・毎月の少人数単位の車座対話（座談会）を信仰体験の共有基盤とする。

---

## 5-1. 事件・不祥事

- **1970年 言論出版妨害事件**:
  藤原弘達著『創価学会を斬る』の出版を巡る妨害工作が政治問題化し、政教分離の徹底・公明党との制度的分離を宣言。
- **1990年代 日蓮正宗との宗門紛争**:
  日蓮正宗僧侶側との教理・運営方針を巡る泥沼の対立と相互批判・訴訟合戦。
