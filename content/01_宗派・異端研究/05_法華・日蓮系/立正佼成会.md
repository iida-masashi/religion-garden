# 立正佼成会 専門構造分析ノート

> [!summary] 要旨
> 立正佼成会（りっしょうこうせいかい）は、[[庭野日敬]]（1906-1999）と[[長沼妙佼]]（1889-1957）が1938年（昭和13年）に霊友会から独立・創立した在家法華仏教教団である。東京都杉並区和田に「大聖堂」を構え、「法座（サンガ）」における対話修行、一乗精神に基づく世界宗教者平和会議（WCRP）推進など、他宗教との対話・国際平和活動を積極的に展開している。

## 3. 創始者と沿革

庭野日敬は霊友会で支部長として活動していたが、法華経の深遠な教理をより平易に日常生活へ生かすことを目指し、長沼妙佼とともに1938年に「大日本立正佼成会」を創立。戦後、法座修行を中心として信徒を急増させ、創価学会と並ぶ巨大教団へと成長した。庭野日敬はローマ教皇パウロ6世との会見やWCRP（世界宗教者平和会議）の設立に尽力し、国際的な平和活動を牽引した。

```
・1938年: 庭野日敬・長沼妙佼により立教

・1964年: 杉並区に「大聖堂」落成
・1970年: 第1回世界宗教者平和会議（WCRP）開催
・1999年: 開祖・庭野日敬死去
```

## 5. 教理・儀礼の特色

- **法座（ほうざ）**: 信徒が車座になり、日々の悩みや信仰体験を語り合い、仏法に照らして心のあり方を省みる集い。
- **一乗精神と諸宗教対話**: あらゆる教えは究極の一仏乗に通じるとし、キリスト教・イスラム教・神道等との平和対話を主導。
