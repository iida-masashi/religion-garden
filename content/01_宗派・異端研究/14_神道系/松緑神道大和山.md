# 松緑神道大和山 専門構造分析ノート

> [!summary] 要旨
> 松緑神道大和山は、1919年 (大正8年) [1952年宗教法人登記]に[[田澤清一]]（1884–1966）等によって創始された新宗教 / 神道系・独自霊示・山岳奉斎の宗教団体。本部は青森県青森市戸山安原（本部聖地）。大和大神崇拝・立国精神・自然敬愛・奉仕実践を中核的教義とし、神道霊示系の系譜に位置づけられる。

## 2. 創始者と沿革

### 創始者の背景と立教
松緑神道大和山の創始者である[[田澤清一]]（1884–1966）は、自らの宗教的体験や思想的研鑽、あるいは時代の精神的背景を受けて教団を設立した。神道霊示系の伝統的教義や技法を吸収しつつ、独自の教義体系を構築した。

### 教団の展開と現代の状況
創始以降、出版活動、布教網の整備、大規模な聖地・大聖堂の建設等を通じて信者層を拡大。現代においても青森県青森市戸山安原（本部聖地）の本部を中心に、教理実践や社会奉仕活動を展開している。

## 4. 教理・儀礼の特色

### 1. 教理構造と救済論
大和大神崇拝・立国精神・自然敬愛・奉仕実践を中心に据え、個人の安心立命や霊的覚醒、先祖供養、あるいは世界平和や社会改革を目指す多層的な救済論を展開する。

### 2. 組織・社会活動の特色

## 5-2. 『新・宗教図鑑』(shu-kyo.com) 全項目深掘り補強・照合データ

### ① 正式属性および細部データ
- **教団名称（読み）**: 松緑神道大和山 (しょうろくしんとうやまとやま)
- **創始者 / 現代表**: 開祖: 田澤清四郎（大和松風） / 現代表: 田澤清喜（大和松園）
- **設立年 / 系統分類**: 1930年 / 系統: 神道
- **公称信者数データ**: 40,000人
- **信仰対象 / 経典神書**: 大和山大神（八百万大神と親神の総称） / 経典: 済度教典、等
- **本部拠点住所**: 青森県東津軽郡平内町
- **スローガン**: 一燈一信

### ② 年表・沿革（歴史変遷データ）
- **1930年**: 現代表・教祖 : 田澤清喜（大和松園）
- **1919年（大正8年）**: 教団の立教 : 青森県青森市の薪炭商であった田澤清四郎（たざわ せいしろう）が、山中での生活中に「九曜の星」の啓示を受けたとして立教。
- **1930年（昭和5年）**: 聖地「大和山」の開拓開始 : 青森県東津軽郡の山中（現在の本部所在地）を「神の鎮まる聖地」と定め、入山。
- **1952年（昭和27年）**: 宗教法人としての認証 : 戦後の宗教法人法制定に伴い、「松緑神道大和山」として包括宗教法人の認証を受ける。
- **2003年（平成15年）**: 第三代教主の継承 : 第二代教主（田澤豊弘／大和松光）の死去に伴い、長男である田澤清喜（きよのぶ）が第三代教主「大和松園（やまとしょうえん）」を継承。
- **2019年（令和元年）**: 立教100周年 : 立教100周年記念大祭を執行。

### ③ 抽出された独自教義・活動の特徴
- 「一燈一信」の教えと社会奉仕
- 「闇夜を照らす一つの燈（あかり）のように、社会の隅々を照らす」という「一燈一信（いっとういっしん）」をスローガンとしている。
- 山中での隠遁的な修行だけでなく、家庭や職場での実践を重視し、「一食を捧げる運動（ユニセフ支援など）」や地域の清掃活動など、地道な社会奉仕活動を行うことが信仰の証とされる。
- 聖地「大和山」での共同体的な祭祀
- 青森県平内町の山間部にある本部は「大和山（やまとやま）」と呼ばれ、独自の自治的なコミュニティを形成している。
- 広大な敷地内には神殿や学校（松風塾高等学校）、宿泊施設があり、信者は定期的に「お山」に帰参して、大祭や練成（修行）に参加する。
- 「奇蹟」よりも「生活の実践」
- 多くの新宗教が「病気治癒」などの奇跡を前面に出すのに対し、大和山は「衣食住の慎み」や「感謝の生活」を説く倫理的な側面が強い。
