# 各教団の食の教義・タブー比較

> [!warning] 出典の性質
> 本ノートは既存の教団別専門ノート（[[自然農法（岡田茂吉）]]、[[クリスチャンヴィーガン食]]、[[末日聖徒イエス・キリスト教会]]、[[こどもおぢばがえりと天理カレー]]等）で既に検証済みの内容を、「食」という切り口で横断的に再整理したものである。個別の確度・留保事項は各教団ノート側の記載に従う。本ノート自体で新たな一次資料検証は行っていない（既存記述の引用・比較にとどまる）。

> [!summary] 要旨
> 本Vaultで扱う教団の「食」への向き合い方は、大きく3つの型に分けられる。(1) **農法・食材の浄・不浄を教義化する型**（世界救世教系の「自然農法」「肥毒」思想）、(2) **特定品目の摂取を明確に禁じる戒律型**（末日聖徒イエス・キリスト教会の「知恵の言葉」）、(3) **教義というより行事・共同体の一体感を支える文化的な食（行事食）型**（天理教の「天理カレー」）。同じ「食」というテーマでも、救済論の中核（浄霊・肥毒思想）に直結する教団もあれば、周辺的な戒律・文化事象にとどまる教団もあり、その濃淡の違い自体が各教団の教義構造の性格を映し出している。

## 1. 型ごとの整理

### 1-1. 農法・食材の浄・不浄を教義化する型（世界救世教系）

| 教団 | 概念 | 内容 |
| :--- | :--- | :--- |
| [[世界救世教]]（[[岡田茂吉]]） | **自然農法・肥毒思想** | 化学肥料・農薬・未熟な糞尿等を「肥毒（土を汚す毒）」として排除し、土本来の生命力（土の威力）を発揮させる無肥料栽培を提唱（1936年研究開始、1950年に名称を「自然農法」に統一）。詳細は[[自然農法（岡田茂吉）]]参照。 |
| [[世界メシア教]] | **クリスチャンヴィーガン食（和ヴィーガン食）** | 動物性食品を一切摂らない完全菜食を、米・大豆製品・発酵食品中心の和の食材と組み合わせ、キリスト（メシア）への愛・感謝・祈りという信仰理念を融合。「身体は神の宿る神殿」であり自然の恵みの摂取で身魂を浄化するという理念。詳細は[[クリスチャンヴィーガン食]]参照。 |
| [[神慈秀明会]] | 自然農法の継承 | 世界救世教から分派した教団だが、母体の浄霊・自然農法の教義を継承。個別の食実践の詳細は本Vaultでは未検証。 |
| [[ミロクコミュニティ救世神教]] | **EM自然農法・「浄霊医学（和方）」** | 農薬不使用の自然農法にEM（有用微生物群）を導入。現代医学（洋方）・東洋医学（漢方）と並ぶ「和方」として浄霊を位置づけ、食と治療を結びつける教義を持つ。 |

> [!note] EM菌を巡る科学的評価の留保
> 上記の自然農法系の一部教団が採用する「EM菌（有用微生物群）」については、日本語版Wikipedia「EM菌」記事が「疑似科学的理論に基づいた」資材と明記しており、科学界からの批判がある点は[[自然農法（岡田茂吉）]]ノートで既に検証・記載済み。教義としての「浄・不浄」観と、資材の科学的評価は区別して扱う必要がある。

### 1-2. 特定品目の摂取を明確に禁じる戒律型

| 教団 | 概念 | 内容 |
| :--- | :--- | :--- |
| [[末日聖徒イエス・キリスト教会]] | **知恵の言葉** | 酒・茶・タバコの摂取を明確に禁止する戒律。教団の教理構造の中核要素の一つとして位置づけられる。詳細は同ノート参照。 |

### 1-3. 行事・共同体の一体感を支える文化的な食（行事食）型

| 教団 | 概念 | 内容 |
| :--- | :--- | :--- |
| [[天理教]] | **天理カレー** | 「こどもおぢばがえり」（1954年開始、毎年20万人以上が参加）期間中に振る舞われる名物カレー。天理教の教義（陽気ぐらし等）自体に食のタブー・戒律は確認されておらず、天理カレーは「同じ会場で同じものを食べる一体感」を育む行事食・共同体形成の文化的装置という性格が強い。2013年にレトルト商品化され天理市の土産物としても親しまれる。詳細は[[こどもおぢばがえりと天理カレー]]参照。 |

## 2. 考察：教義の中核性の濃淡

上記を俯瞰すると、「食」というテーマの教団内での位置づけには明確な濃淡がある。

- **教義の中核に位置する例**: 世界救世教系（自然農法＝肥毒思想は浄霊と並ぶ二大教理の一つ）、末日聖徒（知恵の言葉は教団のアイデンティティを示す代表的戒律）。
- **教義の周辺・文化的事象に位置する例**: 天理教（天理カレーは教義的意味づけよりも共同体的一体感の醸成という機能が主）。

この違いは、教団の成立過程（教祖の実体験・啓示に「食」がどれだけ組み込まれているか）を反映している可能性があるが、この点についての学術的な比較研究の有無は本ノートでは未確認。
