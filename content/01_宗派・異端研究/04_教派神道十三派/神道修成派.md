# 神道修成派 専門構造分析ノート

> [!summary] 要旨
> 神道修成派（しんとうしゅうせいは）は、勤王の志士で新田義貞の末裔を称した[[新田邦光]]（1829-1902）が1876年（明治9年）に黒住教と並び最初に独立認可を受けた教派神道十三派の一派である。東京都杉並区阿佐谷南に本庁を置く。

## 3. 創始者と沿革

新田邦光は幕末の動乱期を経て、人々の道徳頽廃を防ぎ国家社会に尽くす実践倫理として神道を組織化し、教派神道の先駆けとなった。

---

## 4. 歴史変遷クロノロジー

```
・1876年: 教派神道第1号として独立公認
・1902年: 教祖・新田邦光死去
```

## 5. 教理・儀礼の特色

- **修成の教え**: 自己の身を修め、家業に励み、国家社会に報恩感謝すること神道の真髄とする。
