# 金光教 専門構造分析ノート

> [!summary] 要 theorist
> 金光教（こんこうきょう）は、備中国浅口郡の農民・[[赤沢文治]]（金光大神、1814-1883）が1859年（安政6年）に開教した教派神道十三派の一派（幕末三大新宗教の一つ）である。祟り神と恐れられていた「金神（こんじん）」を、万物を生かし育てる慈愛の主神「天地金乃神（てんちかねのかみ）」として捉え直し、「取次（とりつぎ）」による信徒の苦難救済を行っている。

## 3. 創始者と沿革

赤沢文治は重病に際して金神の啓示を受け平癒。1859年に農業を廃業して自宅の座敷（結界）に座り、訪れる人々の苦しみや悩みを聞いて神に取り次ぐ「取次」を開始した。

明治政府の宗教統制下では「神道事務局」所属を経て、1900年（明治33年）に教派神道十三派の最終独立派として「神道金光派」の公認を得た。

## 4. 歴史変遷クロノロジー

```
・1859年: 金光大神、立教（取次業の開始）
・1883年: 金光大神、死去
・1900年: 教派神道として独立公認（神道金光派）
・1946年: 宗教法人金光教として再編
```

## 5. 教理・儀礼の特色

- **天地金乃神と人間関係**: 神と人間は「あいよろこび」の関係にあり、神の助けによって人間が立ち行き、人間の祈りと感謝によって神の神徳が現れるとする。
- **取次（とりつぎ）**: 本部・分教会において広前（ひのまえ）に座る取次者が、信徒の願いや苦悩を直接聞き、神と人との間を仲介する実践。
