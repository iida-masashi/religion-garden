# 出雲大社教 専門構造分析ノート

> [!summary] 要旨
> 出雲大社教（いずもおおやしろきょう）は、明治期の祭神論争（神宮派対出雲派）および神官教導職分離令を受けて、第80代出雲国造・[[千家尊福]]（1845-1918）が1882年（明治15年）に設立・独立した教派神道十三派の一派である。大国主大神を主祭神とし、幽冥事（目に見えない霊的世界・縁結び・死後救済）を司る教義を持つ。

## 3. 創始者と沿革

明治初期、国家神道が祭祀に専念し葬祭や独自の教義宣教を禁じられた際、千家尊福は出雲大社の神職職を弟の千家尊紀に譲り、自らは出雲大社教管長に就任。大国主大神による現世の幸福と幽冥（死後）の霊魂救済を説く全国的な信徒組織を形成した。

---

## 4. 歴史変遷クロノロジー

```
・1873年: 出雲大社敬神講社を設立
・1882年: 神職教導職分離令に基づき「神道出雲派（出雲大社教）」として教派神道独立公認
・1918年: 初代管長・千家尊福死去
・1945年以降: 宗教法人法に基づき包括宗教法人として再編
```

## 5. 教理・儀礼の特色

- **幽顕一如と幽冥主宰**: 顕界（目に見える現世）を天照大御神が治め、幽界（霊界・心・縁・死後の世界）を大国主大神が主宰・保護するという幽顕観。
- **神葬祭の実践**: 神道式葬儀および先祖祭祀の普及。
