# 実行教 専門構造分析ノート

> [!summary] 要旨
> 実行教（じっきょうきょう）は、江戸富士講の中興の祖・食行身禄（1671-1733）の実践躬行・勤労道徳の教えを継承し、神道家・[[柴田花守]]（1809-1890）が1882年（明治15年）に設立・独立した教派神道十三派の一派である。埼玉県さいたま市大宮区に本庁を構える。

## 3. 創始者と沿革

柴田花守は食行身禄の教理をもとに富士山登拝運動を展開し、1882年に教派神道として独立公認を得た。

---

```
・1882年: 教派神道独立公認（神道実行派）

```

## 5. 教理・儀礼の特色

- **実行の教理**: 空論を排し、日々の勤労と道徳的実践躬行を重んじる。
