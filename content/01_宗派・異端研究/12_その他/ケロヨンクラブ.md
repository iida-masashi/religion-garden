# ケロヨンクラブ 専門構造分析ノート

> [!summary] 要旨
> ケロヨンクラブは、オウム真理教から分かれた集団の**通称**である。代表は北澤優子（元オウム真理教在家信者）。1995年の一連の強制捜査後、教団指導部による教義封印等の「改革」に反発した北澤をリーダーとする一団が分裂した。麻原彰晃への帰依と初期オウムの教義・修行を堅持し、2000年に温熱修行中の死亡事故、2004年に竹刀殴打による傷害致死事件と児童虐待事件を起こした。北澤は2011年に東京地裁で懲役8年の判決を受け、2014年に最高裁で確定した。Aleph・ひかりの輪・山田らの集団と異なり、団体規制法の監視対象団体にはなっていない。

---

## 1. 命題の構造（通説・正統本部 vs 本教団・自説）

- 「ケロヨンクラブ」は集団の自称ではなく**通称**である（Wikipedia「ケロヨンクラブ」冒頭）。名称の由来は、「原点に帰る」に引っ掛けてカエルのマスコットを持ち歩いていたことによるとされる（別説として、麻原の肖像の代用品としてケロヨン人形を本尊としていたからという説も脚注に併記されている）。
- 旧ノートは本集団の自称を「真理の勝者」とし、公安調査庁資料・東京地裁判決録等の「確定刑事記録」に基づくと申告していたが、今回照合したWikipedia両記事（「ケロヨンクラブ」「北澤優子」）には「真理の勝者」の記載はなく、判決年・刑期・事件場所・被害者年齢のいずれも旧ノートの記述と食い違った（詳細は§12）。本ノートはWikipedia両記事で確認できる範囲に記述を限定し、確認できない旧来の主張は§12に未検証として分離した。

## 3. 創始者と天啓・社伝

- 代表の北澤優子はオウム真理教の在家信者であった。「我こそは麻原尊師の継承者なり」という神懸り的な言動が目立ち、教団内で煙たがられていたとされる（Wikipedia「ケロヨンクラブ」）。Wikipedia「北澤優子」は北澤を「『麻原尊師の継承者』を自称する原理主義者」と記す。
- 1995年のオウム事件発覚による強制捜査で麻原ら幹部が逮捕され、教団は生き残りのため「ヴァジラヤーナ」教義の封印や麻原の息子を「新教祖」とする改革を行ったが、北澤をリーダーとする一団はこの指導部の動きに反発して分裂した。
- 北澤の生年・経歴の詳細はWikipedia両記事にも記載がなく未確認である。

## 4. 沿革・歴史変遷（検挙・裁判・不敬罪・治安維持法弾圧等）

| 年代 | 事項 | 詳細・背景 |
| :---: | :--- | :--- |
| **1995年** | 分裂 | 強制捜査後、教団指導部の改革に反発した北澤優子をリーダーとする一団がオウム真理教から分裂 |
| **1996年9月** | 肖像画窃盗容疑で逮捕 | 全国各地の神社巡りを行っており、宮崎県の神社から歴代天皇の肖像画を盗んだ容疑で逮捕された（Wikipedia「ケロヨンクラブ」）。麻原が前世の一つを徳川家光としており、日光東照宮にも度々訪れていた |
| **2000年4月16日** | 温熱修行死亡事故 | メンバー一人が温熱修行の最中に死亡。「100℃の温熱修行をやれ（実際に100℃だったかは不明）」と指示したのは北澤だったが、この時は事故として扱われ立件されなかった |
| **2004年9月10日** | 竹刀殴打傷害致死事件 | 修行中のメンバー（2000年に死亡したメンバーの姉、当時36歳）が脱法ドラッグ「ドキュン」を飲まされ、ガムテープで拘束され約2,800回竹刀で打擲された結果死亡した（場所は東京都中野区のアパート。Wikipedia「北澤優子」） |
| **2004年9月24日** | 児童虐待事件発覚 | 「修行」と称して子供5人（7〜13歳）にたばこの火を押し付けるなど虐待をしていた事件が発覚。警視庁公安部は女性信者計3人を傷害容疑で書類送検。子供達は同年10月に児童相談所が保護した |
| **2004年10月** | 北澤逮捕・起訴 | 代表の北澤優子が傷害致死罪で逮捕・起訴された |
| **2011年6月13日** | 東京地裁判決 | 東京地方裁判所の合田悦三裁判長は北澤に懲役8年（求刑懲役10年）を言い渡した |
| **2014年12月8日** | 有罪確定 | 最高裁で有罪が確定（北澤は指示を否定し無罪を主張したが、1・2審とも指示を認定） |
| **2010年頃〜** | 衰退 | 滝本太郎によれば2010年頃にはすでに崩壊寸前であったとされる。一方、2012年当時、横浜の「ケロヨンクラブ」には約28名の信者が在籍していたとの報道もある（デイリー新潮、Wikipedia「北澤優子」経由） |

## 5. 教理・儀礼・神観の深層解剖

- 麻原彰晃への帰依を堅持し、麻原が教祖だった時代のオウム真理教の教義や修行方法を保っている（Wikipedia「ケロヨンクラブ」特徴節）。
- 修行としては、温熱修行のほか、坂を転がり続ける「コンコロリン」、氷を1キログラム砕かず飲み込む修行、生きたミミズ千匹を食べる「ミミズ供養」などが行われていたという。
- 旧ノートにあった「ポア思想」「防毒マスク着用」「窓を塞いだ密室共同生活」等の詳細は、今回照合した出典では確認できなかったため§12に未検証として分離した。

## 6. 宗教学的・歴史社会学的意義

- オウム真理教の後継・分派はAleph・ひかりの輪・山田らの集団が団体規制法の監視対象となっているのに対し、本集団は監視対象となっていない点で、公安上の扱いが異なる小規模原理主義分派の事例である。
- 教団本体の改革（教義封印・教祖交代）への反発から分裂した「原点回帰」型分派が、初期教義・修行の保持の過程で死亡事件に至った事例として、オウム分派研究・カルト問題研究で参照される。
- 2010年頃には崩壊寸前とされながら2012年時点の在籍報道もあり、「摘発＝即時消滅」と単純化できない点も教訓となる。

## 7. 拠点・現地情報

- 東京を拠点とし、都内のマンション・アパートなどの集合住宅に分散して活動していた（Wikipedia「ケロヨンクラブ」）。
- 教団本部・礼拝所等の公的施設の存在は確認できない。2004年の傷害致死事件の現場は東京都中野区のアパートである。
- 旧ノートの「東京都練馬区旭町」拠点説は今回の出典では確認できなかった（§12）。
